# 全局主题执行目标

日期：2026-11-25。状态：实施中。承接[全应用改进目标](../architecture/full-application-improvement-goal.md)。

## 目标

应用拥有的全部 UI 遵循当前主题的设计标准。覆盖生产页面、深层操作、编辑器、导航、弹窗、菜单、提示、加载、空态、错误态及交互状态。不得使用操作系统或浏览器的默认控件外观填补遗漏。

五主题分别执行现有 `themeTokens`、`themeExpression`、`themeMotion` 标准：Minimal 的细线与克制布局、Monet 的柔和晕染、Material 的色调与状态层、Liquid Glass 的透光层次与明确降级、Animal Island 的纸张与手绘风格。颜色、字体、形状、边框、材质、间距、选中、焦点、禁用及动效同时跟随主题。

## 执行范围

- 公共文字与输入：文字、占位、光标、选区、键盘配色、Android 下划线、Web 焦点与自动填充。
- 公共反馈：按钮内等待、页面加载、进度、错误与恢复。应用加载指示器使用主题图形及动效策略。
- 页面与覆盖层：全部生产路由、深层子页、编辑器、确认框、菜单、选择器、工具提示、Toast、抽屉和底部面板。
- 状态完整性：主题切换保留输入宿主、草稿、选区、焦点、展开状态、当前路由及正在执行的操作。
- 防回归：源码审计阻止重新引入原生 Alert、ActionSheet、Toast、Switch、Button、ActivityIndicator 及无主题的 HTML 表单控件；验证别名与命名空间调用。

系统权限页、文件选择器、系统分享面板与输入法由系统控制。应用控制的触发入口、说明、取消和错误反馈仍必须跟随主题；系统界面不计为应用可自定义皮肤。

## 验收

1. 五主题 × 明暗 × 中英日，检查公共控件和全部生产路由及深层入口。
2. 覆盖窄屏、横屏、桌面、大字体、键盘操作、减少动态；禁止削弱焦点可见性和触控范围。
3. 对实际应用组件进行行为测试和浏览器渲染，绑定源码指纹。静态扫描和夹具截图不授予完整应用视觉资格。
4. 记录系统边界、真实失败及待验范围。完整证据闭环前，本专项及原任务的完整验收均保持未完成。
5. 保存原有修改及用户资料；不构建、导出或安装 APK，不触发 Actions，不操作设备音频、TalkBack 或音量。
