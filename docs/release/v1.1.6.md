# IsleMind 1.1.6

<details open>
<summary>简体中文</summary>

### 新功能
- 外观设置新增强调色预览与应用操作，可以先试色，再保存到全应用。

### 改进
- 聊天、历史、设置、提供方、文档与智能体页面采用更轻的层级和留白，空状态提供更明确的下一步。
- 操作结果直接显示在按钮或当前页面，复制、保存和导出的等待、成功与失败状态更清楚，减少对阅读的打断。
- 协调点击、展开、导航与加载反馈，减少输入和流式回复期间的重复动画，并尊重系统的减少动态效果设置。
- 切换主题和深浅模式时保留页面、输入草稿与正在进行的操作，系统外观变化能及时同步。
- 文档库返回后保留搜索与列表状态，编辑和预览切换更直观，保存状态更易辨认。
- 使用统计的请求详情按请求路径、Token、耗时费用和重试异常分组，便于查看每次请求。

### 错误修复
- 修复异常结束或输出受限的回复可能被当作成功、长时间等待或继续执行工具的问题，并保留已经生成的内容。
- 修复部分提供方的端点拼接、结构化输出、附件与推理参数与实际协议不匹配的问题。
- 修复模型发现后部分推理选项和上下文容量不正确的问题，并明确提示已停用服务而不删除已有配置。
- 修正 GPT-5 mini/nano 的标准用量价格估算，避免未知型号和中转端点套用未经确认的价格；历史费用记录保持不变。
- 修复复制或导出失败后仍提示成功，以及异常后不能及时重试的问题。
- 修复部分主题下聊天浮动控件的触控范围、配置页对比度与页面横向溢出问题。

</details>

<summary>English</summary>

### New features
- Preview accent colors in Appearance settings before applying and saving them across the app.

### Improvements
- Use lighter hierarchy and spacing across chat, history, settings, providers, documents, and agents, with clearer next steps in empty states.
- Show action results on the button or current page, making pending, successful, and failed copy, save, and export operations clearer without interrupting reading.
- Coordinate press, disclosure, navigation, and loading feedback, reduce repeated animation during typing and streaming, and respect the system's reduced-motion setting.
- Preserve the current page, input drafts, and ongoing operations when changing themes or light/dark modes, and promptly synchronize system appearance changes.
- Retain document-library search and list state when returning, with clearer editing/preview controls and save status.
- Group request details in Usage by route, tokens, timing and cost, and retries and errors.

### Bug fixes
- Fix interrupted or limited responses potentially being treated as successful, remaining pending, or continuing tool execution, while retaining generated content.
- Fix endpoint assembly, structured output, attachments, and reasoning parameters that did not match some providers' actual protocols.
- Fix incorrect reasoning options and context capacity after model discovery, and clearly identify retired services without deleting saved configuration.
- Correct standard GPT-5 mini/nano usage estimates and avoid applying unverified prices to unknown models or relay endpoints; historical cost records remain unchanged.
- Fix failed copy or export operations reporting success, and restore retry availability after errors.
- Fix floating chat controls' touch bounds, configuration-page contrast, and horizontal overflow in some themes.

<summary>日本語</summary>

### 新機能
- 外観設定でアクセントカラーをプレビューし、確認してからアプリ全体に適用・保存できるようになりました。

### 改善
- チャット、履歴、設定、プロバイダー、文書、エージェント画面の階層と余白を軽くし、空の状態でも次の操作が分かりやすくなりました。
- 操作結果をボタンや現在の画面に表示し、コピー、保存、エクスポートの処理中・成功・失敗を明確にして、読書の中断を減らしました。
- タップ、展開、画面遷移、読み込みの動きを整え、入力やストリーミング中の繰り返しアニメーションを減らし、システムの視差効果を減らす設定に従います。
- テーマやライト・ダークモードの変更時も、現在の画面、入力中の下書き、実行中の操作を保持し、システムの外観変更を速やかに反映します。
- 文書一覧へ戻った際の検索と一覧状態を保持し、編集・プレビューの切り替えと保存状態を見やすくしました。
- 使用統計のリクエスト詳細を、経路、トークン、時間と費用、再試行とエラーに分類しました。

### 不具合修正
- 異常終了や出力制限のある応答を成功と判定したり、待機を続けたり、ツール実行を継続したりする問題を修正し、生成済みの内容を保持します。
- 一部プロバイダーで、エンドポイントの組み立て、構造化出力、添付ファイル、推論パラメーターが実際の通信方式と一致しない問題を修正しました。
- モデル取得後の推論オプションやコンテキスト容量を修正し、保存済み設定を削除せず、提供終了したサービスを明確に表示します。
- GPT-5 mini/nano の標準的な使用料金推定を修正し、未確認のモデルや中継エンドポイントに根拠のない価格を適用しないようにしました。過去の費用記録は変更しません。
- コピーやエクスポートの失敗を成功と表示する問題と、エラー後に再試行できない問題を修正しました。
- 一部テーマで、チャットのフローティング操作部のタッチ範囲、設定画面のコントラスト、横方向のはみ出しを修正しました。

</details>
