# 来源信息按需展开

来源阅读器默认显示简短的版本提示，将详细说明和保存更新时间收进“来源信息”。展开状态按会话、消息和引用身份区分，刷新同一来源时保留状态。中文、英文和日文文案同步提供；来源在回答之后更新的提示仍直接显示。
