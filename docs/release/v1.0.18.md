# IsleMind 1.0.18

<details open>
<summary>简体中文</summary>

### 改进
- 完善中断会话的恢复，让取消和继续操作更明确。
- 改进对话、知识和记忆的读取，减少单条异常记录影响整批内容的情况。
- 统一聊天、设置和服务商页面的主题控件、搜索和模型选择样式。

### 错误修复
- 修复回复状态与消息保存不同步，以及工具续接可能关联错误消息的问题。
- 修复 OpenAI、Anthropic 和 Google 流式回复续接时可能遗漏事件的问题。

本页没有安装包附件。

<summary>English</summary>

### Improvements
- Improve interrupted-chat recovery with clearer cancel and continue actions.
- Improve conversation, knowledge, and memory loading so one invalid record is less likely to block other content.
- Unify themed controls, search, and model-picker styling across Chat, Settings, and Providers.

### Bug fixes
- Fix reply status getting ahead of saved messages and tool continuations linking to the wrong message.
- Fix missing events when continuing streamed replies from OpenAI, Anthropic, and Google.

No installer is attached to this release.
