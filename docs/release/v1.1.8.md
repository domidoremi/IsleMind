# IsleMind 1.1.8

<details open>
<summary>简体中文</summary>

### 新功能
- 跨连接搜索和收藏模型，按全部模型、收藏或单个连接浏览，清楚区分同名模型与别名。
- 保存固定模型或首选与备用模型的路由方案，选用前查看执行顺序，跨连接切换默认询问。
- 将常用模型、路由、技能、提示词、资源与上下文配置保存为场景方案，应用前预览变化和缺失引用；每个会话保留独立配置。
- 上下文检查器区分上次请求和当前草稿预览，可展开来源、纳入与裁剪情况，并分别查看本地估算和供应商回传数量。
- 回答增加用量入口，请求详情展示完整尝试、原选模型、实际目标及供应商报告模型。
- 工具定义增加自动按需方式，较大目录先提供摘要，再取得需要的参数；请求记录可查看首轮工具定义字符数。
- 连接详情增加引用检查，查看关联会话、路由、场景和模型偏好；删除前显示影响范围，并可进入对应配置。

### 改进
- 协调五种主题的设置、详情、路由和资源页面，统一标题、选择状态、留白与操作反馈。
- 改善窄屏、大字体和键盘显示时的布局，主题切换保留正在编辑的内容与焦点。
- 支持模型参数单独配置与思考强度快捷调整，明确当前配置的作用范围。
- 改善供应商模型发现与目录导入，保留来源、请求身份、上游名称和显示别名。
- 完善 MCP、帮助与请求详情的导航和返回位置，补齐中文、英文和日文说明。

### 错误修复
- 修复只加载部分历史时，新建或删除单个会话可能覆盖未加载历史的问题。
- 修复从连接引用打开较早会话时误报不存在的问题，读取失败可重试。
- 修复模型标题更新可能中断点击，以及短窗口内模型菜单被遮挡的问题。
- 修复原生选择列表中部分未选选项无法点击的问题，并保留按钮自定义进度的忙碌状态。
- 修复连接异常提示遮挡首条历史消息，以及部分主题提示操作区域不正确的问题。

<summary>English</summary>

### New features
- Search and favorite models across connections, browse all models, favorites, or one connection, and distinguish models with identical names and aliases.
- Save fixed-model or primary/backup routing plans, preview their execution order, and ask by default before switching connections.
- Save models, routes, skills, prompts, resources, and context settings as scene plans. Preview changes and missing references before applying, with an independent configuration for each conversation.
- Inspect the last request separately from a current draft preview, expand context sources and inclusion or trimming decisions, and distinguish local estimates from provider-reported counts.
- Open usage from a response and inspect complete request attempts, the selected model, actual targets, and provider-reported models.
- Use automatic on-demand tool definitions: larger catalogs provide summaries first and supply parameters as needed. Request records show the initial tool-definition character count.
- Inspect a connection's references to conversations, routes, scenes, and model preferences, review the impact before deletion, and open the relevant configuration.

### Improvements
- Coordinate settings, detail, routing, and resource pages across all five themes, with consistent headings, selection states, spacing, and action feedback.
- Improve layouts on narrow screens, with larger text, and while the keyboard is visible; retain edits and focus when switching themes.
- Configure model parameters individually and adjust reasoning effort through a shortcut, with clearer scope for the current configuration.
- Improve provider model discovery and catalog import while preserving sources, request identities, upstream names, and display aliases.
- Improve navigation and return positions in MCP, help, and request details, and complete Chinese, English, and Japanese guidance.

### Bug fixes
- Fix creating or deleting a single conversation overwriting unloaded history when only part of the history is loaded.
- Fix older conversations opened from connection references being reported as missing, and allow retries after read failures.
- Fix model title updates interrupting clicks and model menus being obscured in short windows.
- Fix some unselected native options being unresponsive, and preserve the busy state of custom button progress indicators.
- Fix connection warnings covering the first historical message and incorrect warning action areas in some themes.

<summary>日本語</summary>

### 新機能
- 接続を横断してモデルを検索・お気に入り登録できます。全モデル、お気に入り、個別接続で絞り込み、同名モデルやエイリアスを区別できます。
- 固定モデル、または優先・予備モデルのルーティングプランを保存できます。実行順序を確認でき、接続を切り替える前には既定で確認します。
- モデル、ルート、スキル、プロンプト、リソース、コンテキスト設定をシーンプランとして保存できます。適用前に変更点や不足する参照を確認し、会話ごとに独立した設定を保持します。
- コンテキスト検査で前回のリクエストと現在の下書きプレビューを区別できます。参照元や採用・削減の判断を展開し、ローカルの推定値とプロバイダーの報告値を別々に確認できます。
- 回答から使用量を開き、リクエストの全試行、選択したモデル、実際の送信先、プロバイダーが報告したモデルを確認できます。
- ツール定義に自動オンデマンド方式を追加しました。大きなカタログは概要を先に提示し、必要に応じてパラメーターを取得します。リクエスト記録では初回のツール定義文字数を確認できます。
- 接続を参照する会話、ルート、シーン、モデル設定を確認できます。削除前に影響範囲を表示し、該当する設定を開けます。

### 改善
- 五つのテーマで設定、詳細、ルーティング、リソース画面を整え、見出し、選択状態、余白、操作結果の表示を統一しました。
- 狭い画面、大きな文字、キーボード表示中の配置を改善し、テーマ切り替え時も編集中の内容とフォーカスを保持します。
- モデルごとのパラメーター設定と推論の強さのクイック調整に対応し、現在の設定の適用範囲を明確にしました。
- プロバイダーのモデル検出とカタログの取り込みを改善し、出所、リクエスト識別子、上流の名前、表示エイリアスを保持します。
- MCP、ヘルプ、リクエスト詳細の移動と戻り位置を改善し、中国語、英語、日本語の説明を補いました。

### 不具合修正
- 履歴の一部だけを読み込んだ状態で会話を作成・個別削除すると、未読み込みの履歴を上書きする問題を修正しました。
- 接続の参照先から古い会話を開く際に存在しないと表示される問題を修正し、読み込み失敗後に再試行できるようにしました。
- モデル名の更新でクリックが中断される問題と、高さの低い画面でモデルメニューが隠れる問題を修正しました。
- ネイティブの選択リストで一部の未選択項目を操作できない問題を修正し、ボタンの独自進捗表示でも処理中の状態を保持します。
- 接続の警告が最初の履歴メッセージを覆う問題と、一部テーマで警告の操作領域が正しくない問題を修正しました。
