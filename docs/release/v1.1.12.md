# IsleMind 1.1.12

<details open>
<summary>简体中文</summary>

### 改进

- 精简请求详情中的执行来源与数量文案。

### 错误修复

- 修正聊天阅读栏宽度变化时可能持续更新消息列表的问题。
- 切换会话路由方案后，配置状态提示及时刷新。
- AI 配置中的数字参数输入框保持在键盘上方。
- 关闭 AI 配置或进入连接管理时，保存尚未失焦的数字参数，并清除已关闭输入框的焦点。

</details>

<details>
<summary>English</summary>

### Improvements

- Simplify execution source labels and quantity text in request details.

### Bug fixes

- Fix repeated message list updates when the chat reading column changes width.
- Refresh configuration status when the conversation routing plan changes.
- Keep numeric parameter fields in AI configuration above the keyboard.
- Save pending numeric parameters when closing AI configuration or opening connection management, and clear focus from the closed fields.

</details>

<details>
<summary>日本語</summary>

### 改善

- リクエスト詳細の実行元と件数の表記を簡潔にしました。

### 不具合修正

- チャットの表示幅が変わると、メッセージ一覧の更新が繰り返される問題を修正しました。
- 会話のルーティングプランを切り替えると、設定状態の表示が更新されます。
- AI 設定の数値入力欄がキーボードに隠れないようにしました。
- AI 設定を閉じる際や接続管理へ移動する際に、入力中の数値パラメータを保存し、閉じた入力欄のフォーカスを解除します。
