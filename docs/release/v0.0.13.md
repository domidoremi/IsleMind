# IsleMind 0.0.13

<details open>
<summary>简体中文</summary>

### 改进
- 改进 Grok、Qwen、Claude、Gemini 和 MiniMax 等模型的能力识别。
- 更清楚地显示请求连接、代理、参数调整和兼容回退状态。
- 回复状态区分准备、生成、推理和工具处理阶段。
- Vertex AI 兼容地址仍需手动维护模型列表。

### 错误修复
- 修复同一域名的 OpenAI 和 Anthropic 兼容地址导入成重复服务商的问题。
- 修复导入时将地址或协议标签误保存为密钥的问题。
- 修复多端点服务商的模型同步和自定义地址识别问题。
- 修复 MiMo 参数错误被误判为连接失效的问题，不支持的参数会尝试一次兼容重试。
- 修复模型不存在时的错误分类，以及内部工具内容混入回复的问题。
- 修复导入表单被键盘遮挡、模型列表滚动受限和推理内容展开错误的问题。

</details>

<summary>English</summary>

### Improvements
- Improve capability detection for models including Grok, Qwen, Claude, Gemini, and MiniMax.
- Show connection, proxy, parameter adjustment, and compatibility fallback status more clearly.
- Distinguish preparation, generation, reasoning, and tool stages in reply status.
- Model lists for Vertex AI compatible endpoints still need to be maintained manually.

### Bug fixes
- Fix OpenAI and Anthropic compatible addresses on the same host creating duplicate providers during import.
- Fix addresses or protocol labels being incorrectly saved as keys during import.
- Fix model synchronization and custom-address recognition for providers with multiple endpoints.
- Fix MiMo parameter errors being mistaken for connection failures, with one compatibility retry for unsupported parameters.
- Fix error classification for missing models and internal tool content appearing in replies.
- Fix keyboard overlap in provider import, restricted model-list scrolling, and incorrect expanded reasoning content.
