# 来源阅读器说明精简

已就绪的来源阅读器原先在标题、摘要、展开说明和分段标题中反复表达“当前保存的文字”。现在直接以来源标题组织正文：收起详情时保留简短摘要，展开时显示一次完整说明。分段标题保留编号和引用标记，中、英、日三种语言同步精简。

来源异常和加载状态继续提供原有提示。刷新、引用分段切换、捕获文字与来源更新时间的逻辑保持原有行为。

验证通过：

- 从 `main` 生成独立候选，完整 JSON 比较确认每种语言只修改两条分段文案；候选 5 项位置与资料保留回归、TypeScript 和两项架构检查通过。
- 工作区 TypeScript 通过。既有位置测试在调整前后都因摘录元件缺少安全区上下文而失败；独立测试环境加入官方安全区 mock 后，实际工作区的 5 项回归通过，原测试文件没有修改。
- 实际 320×844、英文、Minimal 浅色浏览器验证标题、收起与展开说明、刷新、三个分段与精确引用分段切换，以及返回原回答。正文与捕获文字一致，原设置、会话及全部浏览器存储哈希精确还原，没有模型请求。

本项没有新的截图验收。此前同一浏览器页面的两次截图均逾时，继续保留失败记录。Android 的完整阅读器流程沿用先前验收范围，本项候选尚未同步到原生暂存源码；整体验收标志保持 false。

证据位于 `test-evidence/release/source-reader-copy-20261114-01/`；浏览器结果为 `source-reader-copy-320-53.json` 和 `source-reader-copy-browser-restored-54.json`，位于 `test-evidence/implementation/reader-routing-info-2026-11-13/ego-main-readers-20261114-01/`。
