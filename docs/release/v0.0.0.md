# IsleMind 0.0.0

<details open>
<summary>简体中文</summary>

### 新功能
- 新增聊天、会话、设置、知识和记忆界面，提供简体中文、英文和日文界面。
- 支持配置多个 AI 服务商，管理凭据组、同步模型并切换服务商与模型。
- 加入上下文管理、联网搜索、语音输入和朗读的基础功能。
- 对话与设置保存在本机，服务商密钥使用设备安全存储。

</details>

<summary>English</summary>

### New features
- Add Chat, Conversations, Settings, Knowledge, and Memory screens with Simplified Chinese, English, and Japanese interfaces.
- Configure multiple AI providers, manage credential groups, synchronize models, and switch providers and models.
- Introduce basic context management, web search, voice input, and read-aloud features.
- Keep conversations and settings locally and store provider keys in secure device storage.
