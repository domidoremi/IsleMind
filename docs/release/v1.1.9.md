# IsleMind 1.1.9

<details open>
<summary>简体中文</summary>

### 新功能

- 为引用分段和完整保存文本分别保留阅读位置，来回切换时可继续阅读。

### 改进

- 精简来源标题、分段标签与重复说明，按需展开详细来源信息。
- 模型来源的时间按照界面语言显示，中文、英文与日文保持一致。
- 避免文档保存状态的隐藏文字被重复朗读。

### 错误修复

- 修复从帮助返回来源页后正文或阅读位置丢失的问题。
- 修复网页首页无法读取既有会话历史的问题。
- 修复部分知识文档导入后段落换行丢失的问题。
- 修正文档复制范围的英文和日文说明，明确仅复制编辑正文。
- 修复网页切换语言后，辅助工具仍按英文识别页面语言的问题。

</details>

<details>
<summary>English</summary>

### New features

- Keep separate reading positions for the cited section and the complete saved source, so you can continue reading when switching views.

### Improvements

- Simplify source titles, section labels, and repeated explanations, with detailed source information available on demand.
- Display model source timestamps in the interface language, consistently in Chinese, English, and Japanese.
- Prevent hidden document save labels from being read repeatedly by assistive tools.

### Bug fixes

- Fix source text or reading positions being lost when returning from help.
- Fix the web home page failing to load existing conversation history.
- Fix paragraph breaks being lost when importing some knowledge documents.
- Correct English and Japanese document guidance to clarify that only the editable body is copied.
- Fix assistive tools identifying the page as English after the web interface language changes.

</details>

<details>
<summary>日本語</summary>

### 新機能

- 引用区間と保存された全文で読んでいた位置を個別に保持し、表示を切り替えても読み続けられます。

### 改善

- 出典の見出し、区間ラベル、重複する説明を整理し、詳細な出典情報を必要に応じて展開できます。
- モデルの情報源の時刻を画面の言語で表示し、中国語・英語・日本語で一貫した表示にしました。
- ドキュメントの保存状態を示す非表示の文字が、重複して読み上げられる問題を改善しました。

### 不具合修正

- ヘルプから出典画面に戻ると本文や読んでいた位置が失われる問題を修正しました。
- Web のホーム画面で既存の会話履歴を読み込めない問題を修正しました。
- 一部のナレッジ文書を取り込むと、段落の改行が失われる問題を修正しました。
- ドキュメントの英語・日本語の説明を修正し、コピー対象が編集本文のみであることを明確にしました。
- Web の表示言語を変更した後も、支援ツールがページを英語として認識する問題を修正しました。

</details>
