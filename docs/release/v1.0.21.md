# IsleMind 1.0.21

<details open>
<summary>简体中文</summary>

### 改进
- 重新生成回复前增加确认，减少误操作。
- 批量导入服务商时忽略列表编号，并可根据地址识别名称和预设。
- 精简空会话输入框和顶部状态提示。

### 错误修复
- 修复窄屏下助手消息过宽和生成动画影响布局的问题。
- 修复同一通知可能因显示位置不同而重复出现的问题。

</details>

<details>
<summary>English</summary>

### Improvements
- Ask for confirmation before regenerating a reply to reduce accidental replacement.
- Ignore list numbering during bulk provider import and recognize names and presets from the supplied configuration.
- Simplify the empty-chat composer and top status text.

### Bug fixes
- Fix overly wide assistant messages and generation animations disrupting narrow-screen layouts.
- Fix the same notice appearing repeatedly at different display locations.

</details>
