### 改进

- 搜索框采用主题正文排版与用户选定字体。
- 进度文字使用各主题的辅助文字样式。
- 加载、错误与操作反馈遵循主题文字样式和用户选定字体。
- 工作区介绍在切换主题或字体时保留标题与正文层级。
- 动物岛工具提示使用用户选定字体，并保留工具提示的文字样式。
- 服务商来源摘录、范围信息和提示文字遵循主题排版；切换主题或字体时保留展开状态，摘录仍可选择。

### 错误修复

- 修复 Material 和 Liquid Glass 表面上的单选标记对比不足的问题。

<summary>English</summary>

### Improvements

- Search fields use theme body typography and the selected font.
- Progress labels use each theme's supporting text styles.
- Loading, error, and action feedback follow theme text styles and the selected font.
- Workspace introductions retain their title and body hierarchy when themes or fonts change.
- Animal Island tooltips use the selected font while retaining their tooltip text styles.
- Provider source excerpts, range information, and notices use theme typography. Switching themes or fonts preserves the expanded state and selectable excerpts.

### Bug fixes

- Fixed insufficient contrast for selected radio indicators on Material and Liquid Glass surfaces.

<summary>日本語</summary>

### 改善

- 検索欄にテーマの本文スタイルと選択したフォントを適用します。
- 進捗表示に各テーマの補助テキストのスタイルを適用します。
- 読み込み、エラー、操作結果の表示にテーマの文字スタイルと選択したフォントを適用します。
- テーマやフォントを切り替えても、ワークスペースの紹介文の見出しと本文の階層を保ちます。
- 動物の島のツールチップに選択したフォントを適用し、ツールチップの文字スタイルを保ちます。
- プロバイダーの出典抜粋、範囲情報、注意書きにテーマの文字スタイルを適用します。テーマやフォントを切り替えても展開状態を保ち、抜粋の文字を選択できます。

### 不具合修正

- Material と Liquid Glass の背景で、選択済みのラジオマークのコントラストが不足する問題を修正します。
