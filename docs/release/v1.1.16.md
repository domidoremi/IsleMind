# IsleMind 1.1.16

<details open>
<summary>简体中文</summary>

### 错误修复

- 网页启动遇到短暂的存储占用时自动恢复。
- 离线手册搜索不再返回仅匹配图片文件名或隐藏锚点的章节。
- 快速切换会话时，草稿只保存一次，切回后正文完整。
- 网页聊天使用输入法在正文中间输入时，光标保留在输入位置。
- 放弃未保存文档并返回聊天后，输入焦点正常释放。

</details>

<details>
<summary>English</summary>

### Bug fixes

- Recover automatically when web startup encounters a brief storage lock.
- Exclude image filenames and hidden anchors from offline guide search results.
- Save a draft once when switching conversations quickly, and restore its full text when returning.
- Keep the caret at the insertion point when composing text with an IME in web chat.
- Release input focus after discarding an unsaved document and returning to chat.

</details>

<summary>日本語</summary>

### 不具合修正

- Web 版の起動時にストレージが一時的に使用中でも、自動で復帰します。
- オフラインガイドの検索で、画像ファイル名や非表示のアンカーだけに一致する章が表示されないようにしました。
- 会話をすばやく切り替えたときに下書きが重複して保存される問題を修正しました。戻ったときも本文が保たれます。
- Web 版のチャットで本文の途中に IME 入力しても、カーソルが入力位置に残るようにしました。
- 未保存の文書を破棄してチャットに戻ると、入力フォーカスが解除されます。
