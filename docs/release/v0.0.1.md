# IsleMind 0.0.1

<details open>
<summary>简体中文</summary>

### 新功能
- 新增首页、会话和设置三页滑动导航，以及独立服务商管理入口。

### 改进
- 服务商支持筛选、拖动排序和批量启用，方便整理较多配置。
- 凭据按组管理，模型列表默认只读，减少误改。
- 首页同步显示当前服务商和模型，模型选择弹层可点击外部关闭。
- 改善冷启动更新检查，减少漏报新版本。

</details>

<details>
<summary>English</summary>

### New features
- Add a Home, Conversations, and Settings pager with a separate provider-management entry point.

### Improvements
- Filter, drag-sort, and bulk-activate providers for easier configuration management.
- Manage credentials in groups and keep model lists read-only by default to reduce accidental edits.
- Show the active provider and model on Home and dismiss the model picker by tapping outside it.
- Improve cold-start update checks to reduce missed versions.

</details>
