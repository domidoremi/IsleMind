# 结构化导入密钥去重与真机批量保存

## 源码改动

连接编辑器保存结构化导入草稿时，先读取安全存储中的已有密钥身份。重复密钥复用保留组的 ID，保留原名称、模型归属、启停及健康记录；导入的首选引用映射到该组。新密钥继续使用独立组。已有重复组不在本次合并范围。

安全读取失败时不写入配置，草稿可重试；组件卸载后停止待执行保存。主线同步补齐本项所需的导入策略本地状态、未保存检测、放弃恢复和保存逻辑。其余未完成工作保持。

## 失败与范围

首轮重载因误引旧缓存基线在设备重载前停止；实际重载就绪检查出现一次 Inspector 超时。新场景助手首次因错误的依赖文件名在执行前停止。结构化导入识别并清空输入后，浏览器 `fill` 超时；后续核对现存草稿并以真实粘贴完成流程。IPv6脚本读取被拒绝后，核对实际监听在 IPv4。类型检查的一处可空字符串错误已修正，并重跑最终测试、Web流程及源码绑定。所有失败记录保留。

首轮程序化焦点矩阵在第13个状态停止；观察到按钮底部越界1.5像素，实际 Tab 将其完整带入视口。后续60组合使用真实 Tab 通过，首轮失败保留。Web截图未取得合格目视证据；原生两张图片仅目视中文岛屿深色原竖屏的可见区域。

原生内存问题继续开放：场景结束后 PSS 为 1,448,918 KB，其中 Native Heap PSS 为 1,008,948 KB。31路由／55原型、完整环境视觉、系统大字体、静默原生无障碍、输入与真实存储故障、恢复及性能继续；设备音频、TalkBack和音量未操作。未构建、导出、安装APK或派发工作流。四项整体验收资格保持 false。
