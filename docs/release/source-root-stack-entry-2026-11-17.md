# 根导航默认首页

根导航在没有可用导航状态时默认进入首页。此前显式登记的第一个页面是上下文设置，未指定默认路由，空状态或失效页面恢复可能进入该设置页。本项为根 Stack 增加 `initialRouteName="index"`。已有有效页面和显式链接继续使用原目标及参数。

619 从真机实际挂载的根布局读取 Stack 配置，并将其交给已加载的路由器纯函数：初始化、空状态恢复、旧页面移除三条回退均为 `settings/context`；同一运行时指定首页后三条均为 `index`，显式上下文链接参数保留。完整加载脚本与之前核对的运行字节一致，根布局及三个路由库文件源码映射匹配。此证据确认默认入口缺陷，尚不能说明每次历史源码同步为何失去可恢复导航状态。

新增五项回归执行实际根布局并使用已安装路由器，原生服务和无关界面替换为惰性夹具。旧实现四项失败、显式链接一项通过；修复后工作区三组共 29 项通过，类型检查通过。仅从 main 提取根布局并增加本属性的独立候选五项通过；最终夹具补充 main 中现存的全局状态层后，工作区五项复验通过。没有声称整个独立 main 工程通过类型或全量测试。

保留 620 夹具展开原生 getter 导致 DevMenu 依赖失败、623 独立候选缺少夹具依赖的失败；均未执行产品场景。622 首次候选准备因 main 没有工作区新增的导航包装而在文件写入前停止，改用唯一 Stack 起始标签后只增加本属性，其他工作区差异保持。
