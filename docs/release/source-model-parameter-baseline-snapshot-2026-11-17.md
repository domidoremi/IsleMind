# 固定发送请求的模型参数基线

日期：2026-11-17。[完整应用目标](../architecture/full-application-improvement-goal.md)继续进行中。

## 行为与原因

请求快照现在复制并冻结模型参数基线，包括原始数值与参数来源。切换连接或模型时，系统先恢复该基线，再应用目标模型默认值。之前基线对象仍引用调用方数据，发送准备期间的后续修改可能改变温度、输出上限，或将显式会话值误判为可由目标模型覆盖的默认值。

本次仅增加基线快照，不修改默认值优先级、实时撤销端口、信号或执行身份。显式会话温度保持；目标连接的输出默认值按原规则应用；目标没有覆盖时保留原始预留值和线上参数省略行为。
