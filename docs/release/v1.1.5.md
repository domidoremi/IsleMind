# IsleMind 1.1.5

<details open>
<summary>简体中文</summary>

### 新功能
- 可选择更新检查间隔，以及只接收稳定版或接收所有合格发布。
- 新增默认关闭的 APK 自动准备选项，开启前会说明 Wi-Fi 使用策略，并单独征求同意。

### 改进
- 临时提示统一在顶部单条显示，只淡入淡出，不再从底部向上弹出。
- 更新提醒避开输入、回复生成、编辑和弹层，等待闲时再显示。
- 已批准的更新可等待前台空闲再交给安装器；设置中可查看说明或取消待处理更新。
- 更新说明按分类汇总跨版本改动，并保留每条改动的来源版本。
- 调整 Material 主题聊天空状态的按钮居中和初始配置页面的左右留白。

### 错误修复
- 修复取消下载后，旧的进度提示可能覆盖最终结果的问题。
- 安装操作始终绑定用户批准的版本，交接前重新校验下载文件，避免使用过期或被修改的 APK。
- 修复更新检查可能采用尚未完成读取的设置，以及检查失败后不能及时重试的问题。

安装包以对应 Release 的实际附件为准。

<summary>English</summary>

### New features
- Choose update-check intervals and whether to receive stable versions only or all eligible releases.
- Add an optional, default-off APK preparation setting with an explanation of the Wi-Fi policy and separate consent.

### Improvements
- Show transient feedback one item at a time at the top, using fades instead of sliding up from the bottom.
- Wait for quiet time before showing update reminders, avoiding typing, response generation, editing, and open dialogs.
- Approved updates can wait for foreground idle time before installer handoff; review notes or cancel pending updates in Settings.
- Group cumulative changes by category while preserving the source version of each change.
- Center the Material theme's empty-chat actions and balance spacing on the initial setup page.

### Bug fixes
- Fix stale download progress potentially replacing the final result after cancellation.
- Keep installation bound to the approved version and recheck downloaded files before handoff, avoiding stale or modified APKs.
- Fix update checks potentially using settings before hydration finishes, and improve retries after failed checks.

Installers are available only when attached to the corresponding Release.

<summary>日本語</summary>

### 新機能
- 更新確認の間隔と、安定版のみ、またはすべての適格なリリースを受け取る設定を追加しました。
- 初期状態で無効な APK 自動準備設定を追加しました。有効化する前に Wi-Fi ポリシーを説明し、個別に同意を求めます。

### 改善
- 一時的な通知を画面上部に一件ずつ表示し、下からせり上がる動きではなくフェードで切り替えます。
- 入力、回答生成、編集やダイアログを妨げず、操作が落ち着いてから更新通知を表示します。
- 承認した更新は前面でのアイドル状態を待ってからインストーラーへ引き渡せます。設定で説明の閲覧や保留中の更新のキャンセルが可能です。
- 更新内容を分類別にまとめ、各変更のバージョンを表示します。
- Material テーマの空チャット画面でボタンを中央に配置し、初期設定画面の左右の余白を調整しました。

### 不具合修正
- ダウンロードをキャンセルした後、古い進捗通知が最終結果を上書きする可能性を修正しました。
- 同意したバージョンだけをインストールし、引き渡し前にファイルを再検証して、古い APK や変更された APK の使用を防ぎます。
- 設定の読み込み完了前に更新確認が行われる可能性を修正し、確認失敗後の再試行を改善しました。

インストーラーは、該当リリースに実際に添付されているものだけが利用できます。
