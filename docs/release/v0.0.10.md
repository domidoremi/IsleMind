# IsleMind 0.0.10

<details open>
<summary>简体中文</summary>

### 改进
- 输入框常用操作采用紧凑图标布局，增加小屏幕输入空间。
- 服务商页面增加选择模式和批量导入入口。
- Android 通知显示回复完成、停止和错误状态。
- 冷启动时显示明确的应用启动提示。

### 错误修复
- 修复 Android 系统区域遮挡标题、消息或输入控件的问题。
- 修复消息重叠和旧布局残留的问题。
- 修复联网搜索没有结果或失败时只显示空白的问题。

</details>

<details>
<summary>English</summary>

### Improvements
- Use compact icons for common composer actions to preserve input space on small screens.
- Add selection mode and bulk import to the provider page.
- Show completed, stopped, and error reply states in Android notifications.
- Show a clear starting indicator during cold launch.

### Bug fixes
- Fix Android system areas covering headers, messages, or input controls.
- Fix overlapping messages and stale layouts.
- Fix web search showing blank content when no results are available or a search fails.

</details>
