# IsleMind 0.0.6

<details open>
<summary>简体中文</summary>

### 新功能
- 新增首次使用引导、工作区就绪检查、记忆审阅和可继续处理的工作结果。
- 扩展聊天内置命令和工具，可从对话中调用更多工作区操作。
- 新增运行日志、服务商健康、连接方式选择和远程上下文压缩控制。

### 改进
- 改进服务商地址和协议选择，以及请求失败时的切换处理。
- 完善聊天、设置和服务商导入的状态反馈，调整导航动画。
- 减少敏感运行信息进入可分享工作结果的情况。
- 移除上一版本的实验性首页宠物。

</details>

<details>
<summary>English</summary>

### New features
- Add onboarding, workspace-readiness checks, memory review, and resumable work results.
- Expand built-in chat commands and tools for more workspace actions.
- Add runtime logs, provider health, connection selection, and remote context compression controls.

### Improvements
- Improve provider-address and protocol selection and switching after request failures.
- Improve Chat, Settings, and provider-import feedback and refine navigation animation.
- Reduce sensitive runtime information in shareable work results.
- Remove the previous version's experimental Home pet.

</details>
