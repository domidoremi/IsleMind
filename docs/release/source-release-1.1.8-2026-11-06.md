# IsleMind 1.1.8 源码发布记录

日期：2026-11-06。本次按用户要求将当前成果拆分提交、推送并发布源码版本，不触发构建。源码版本为 `1.1.8`，Android 版本码为 `133`；公开更新说明见 [v1.1.8.md](./v1.1.8.md)。

## 发布范围

本版包括当前工作区已实现的模型发现与参数配置、跨连接模型搜索和收藏、上下文检查、路由方案、请求尝试与用量归属、工具按需发现、场景方案、连接引用和删除影响，以及页面主题、导航、键盘和历史持久化修复。各模块沿用原有所有者；共享契约、执行组合和页面呈现分别保留边界。

提交按共享契约、供应商、设置持久化、会话、诊断、运行时、共享界面、聊天、设置页面、依赖、验收脚本、文档和版本拆分。每组实现保留相关行为测试，详细验收报告链接于 [文档入口](../README.md)。本次没有继续扩展产品功能。

原生组件依赖的两项修复分别提交到 `domidoremi/animal-island-ui` 的 `rn` 分支：Button 保留宿主忙碌状态，Select 保留原生启用选项的焦点和点击动作。IsleMind 的固定依赖更新为远端可获取的 `412d55dd1a1e0e79baacfca34204b97494822a8b`；没有使用移动分支作为构建输入。此前 H 批记录中的未提交依赖状态是当时的验证状态，本次提交未改变这些已验证组件的源码。

## 构建与更新清单

IsleMind 的 APK 和网站工作流仅支持手动触发，架构与供应商维护工作流支持 Pull Request 和手动触发；当前工作流没有推送、标签或 Release 触发器。UI 依赖的 CI 仅在 `main` 推送或面向 `main` 的 Pull Request 触发，本次只推送 `rn`。本次不创建 Pull Request、不派发工作流，也不执行本地构建、导出或安装。

沿用 1.1.7 的源码发布方式，标签为 `v1.1.8`，GitHub Release 正文与公开三语说明一致，不上传 APK。`updates/android.json` 保留原有 `1.1.2` / `127` 候选身份和空资产列表，不将源码版本冒充可安装更新。测试证据、截图和本地研究继续遵循仓库忽略规则。

发布检查和提交明细存于工作区 `test-evidence/release/v1.1.8-20261106/`。这些本地记录不作为公开下载资产。
