# IsleMind 0.0.8

<details open>
<summary>简体中文</summary>

### 新功能
- 新增分步智能体工作流，可查看计划、工具操作和结果，并在确认后保存到 Skills。
- 新增 Android 闹钟、日历、APK 安装、授权文件夹和应用缓存操作，系统操作或写入前会先确认。
- 扩展会话搜索，可按标题、服务商、模型、提示词和最近消息查找。
- 新增 Android 生成状态通知，可查看进度并返回对应会话。

### 改进
- 改善长回复、代码、表格和公式阅读，以及重命名和删除反馈。
- 增加混合与智能体知识检索，优化图片和大内容加载。
- 完善输入框快捷控制、字符与附件计数、推理选项和无障碍说明。
- 导入的工作流默认停用，审核后才可启用；文件操作仅限系统选择器授权的目录。
- 改善凭据和本地数据存储的兼容处理。

### 错误修复
- 修复主界面和对话框的状态栏背景与图标对比度问题。

<summary>English</summary>

### New features
- Add step-based agent workflows with plans, tool actions, and results, plus confirmed saving to Skills.
- Add Android alarm, calendar, APK installation, authorized-folder, and app-cache actions, with confirmation before external or write actions.
- Expand conversation search across titles, providers, models, prompts, and recent messages.
- Add Android generation-status notifications for following progress and returning to the conversation.

### Improvements
- Improve reading of long replies, code, tables, and formulas, with clearer rename and delete feedback.
- Add hybrid and agentic knowledge retrieval and improve image and large-content loading.
- Improve composer shortcuts, character and attachment counts, reasoning controls, and accessibility guidance.
- Keep imported workflows disabled until reviewed and restrict file actions to folders authorized through the system picker.
- Improve compatibility handling for credential and local-data storage.

### Bug fixes
- Fix status-bar backgrounds and icon contrast on main screens and dialogs.
