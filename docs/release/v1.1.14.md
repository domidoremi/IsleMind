# IsleMind 1.1.14

<details open>
<summary>简体中文</summary>

### 错误修复

- 修复路由组切换成员时，待发请求的模型参数基线可能被后续修改影响的问题。
- 模型列表跳过已停用的密钥组，并将模型别名归入对应上游模型的有效密钥组。
- 修正英文模型数量的单复数显示。
- 岛屿主题搜索模型时显示匹配连接数与总数。
- 没有可用导航状态时默认进入首页，避免误入上下文设置。

</details>

<details>
<summary>English</summary>

### Bug fixes

- Keep pending model parameter baselines stable when a routing group switches members.
- Skip disabled credential groups in the model list and place aliases in the active group for their upstream model.
- Correct singular and plural model counts in English.
- Show matching connections and the total when searching models in the Island theme.
- Default to the home page when no usable navigation state exists, preventing an unintended visit to context settings.

</details>

<details>
<summary>日本語</summary>

### 不具合修正

- ルーティンググループの接続先を切り替える際、送信待ちリクエストのモデルパラメーター基準値が後続の変更に影響される問題を修正しました。
- モデル一覧で無効な認証情報グループを除外し、エイリアスを対応する上流モデルの有効なグループに分類します。
- 英語のモデル件数表示で単数形と複数形を修正しました。
- 島テーマのモデル検索で、一致する接続数と総数を表示します。
- 有効なナビゲーション状態がない場合はホームを開き、コンテキスト設定への意図しない移動を防ぎます。

</details>
