# IsleMind 0.0.14

<details open>
<summary>简体中文</summary>

### 新功能
- 模型设置显示能力的推断、手动声明、已验证或不支持状态，以及最近测试结果。
- 新增协议选择、兼容回退和凭据健康信息，改善长对话的连接处理。
- 诊断页面新增事件时间线、服务商健康和修复入口。
- 插件列表显示未审核、已批准和已拒绝状态。
- Android 闹钟、日历和提醒显示目标时间与内容，需要时打开系统应用确认。

### 改进
- 服务商导入显示解析、保存和刷新进度，批量结果按问题分组。
- 支持单独清理无密钥或配置无效的服务商。
- 减少批量启用后的重复刷新和等待，改善服务商较多时的流畅度。
- 移除多步首次启动引导，改由主页和设置完成配置。
- 调整生成阶段名称，不再把所有处理都显示为“思考”。
- 外部诊断数据发送默认关闭，启用前需确认。

### 错误修复
- 修复批量启用服务商时配置与凭据健康状态互相覆盖的问题。

### New features
- Show inferred, manually declared, verified, or unsupported model capabilities and the latest test results.
- Add protocol selection, compatibility fallback, and credential health information for long conversations.
- Add a diagnostic event timeline, provider health information, and repair actions.
- Show unreviewed, approved, and rejected states in the plugin list.
- Show target times and content for Android alarms, calendar items, and reminders, opening the system app for confirmation when needed.

### Improvements
- Show parsing, saving, and refresh progress during provider import, with bulk results grouped by issue.
- Clean up providers with missing keys or invalid configuration separately.
- Reduce repeated refreshes and waiting after bulk activation, especially with many providers.
- Remove multi-step onboarding and configure capabilities from Home and Settings instead.
- Use clearer generation-stage names instead of labeling every phase as thinking.
- Keep external diagnostic sending off by default and require consent before enabling it.

### Bug fixes
- Fix provider configuration and credential health overwriting each other during bulk activation.
