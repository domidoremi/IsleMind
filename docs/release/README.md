# 更新说明

本目录的 `v*.md` 是面向用户的更新说明，与同名 GitHub Release 的正文保持一致。
历史说明沿用各发布页已有的语言，不改变原来的标签、发布日期、预发布状态或附件。

## 写法

- 按“新功能 / 改进 / 错误修复”分类，只显示有实际内容的分类。
- 每条直接说明用户能做什么、哪里更好用，或修复了什么问题，避免写成操作教程或实现说明。
- 只写该版本的真实变化，不把后续版本的功能追加到历史版本。
- 测试数量、提交记录、构建过程和技术边界不放进公开更新说明；维护记录另见 [google-play.md](./google-play.md)。
- 下载说明以对应 Release 的实际附件为准；标签与应用版本不一致时保留简短说明，不虚构安装包。
