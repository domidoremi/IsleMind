# IsleMind 0.0.15

<details open>
<summary>简体中文</summary>

### 新功能
- 新增回复用量页面，可按服务商、模型和来源查看请求、Token、延迟与错误统计。
- 支持设置模型显示名称，并增加自定义服务商入口和模型能力状态。
- 新增 Markdown 和“酸橙公路”主题，支持跟随系统及预设或自定义强调色。
- 工作流新增任务卡，可查看进度、结果与待确认操作。
- 语音输入显示权限、录音、转写、取消和失败状态。

### 改进
- 用量页面区分服务商返回的数据与本地估算。
- 改进服务商中转兼容性，以及消息状态、长按操作和知识、记忆筛选。
- 改进 Android 状态通知的后台维持与失败反馈。
- 旧 Glass 主题选择会迁移为 Markdown 主题。
- 加强安装包校验和网页地址检查，减少损坏下载与不安全跳转。

### 错误修复
- 修复 Android 启动失败时可能长时间没有提示的问题。
- 修复 Android 键盘与输入框同时调整高度造成的布局问题。
- 修复无安装包的 Release 可能被误认为可安装更新的问题，并完善下载进度显示。

</details>

### New features
- Add a reply-usage page with request, token, latency, and error statistics by provider, model, and source.
- Set model display names and access custom-provider setup and clearer model capability states.
- Add Markdown and Lime Road themes, system appearance, and preset or custom accent colors.
- Add workflow task cards for progress, results, and pending actions.
- Show permission, recording, transcription, cancellation, and failure states for voice input.

### Improvements
- Distinguish provider-reported usage from local estimates.
- Improve relay compatibility, message status, long-press actions, and knowledge and memory filters.
- Improve background handling and failure feedback for Android status notifications.
- Migrate existing Glass theme selections to Markdown.
- Strengthen installer verification and web-address checks to reduce corrupt downloads and unsafe redirects.

### Bug fixes
- Fix Android startup failures potentially remaining without feedback for a long time.
- Fix layout issues caused by competing Android keyboard and composer resizing.
- Fix releases without installers potentially being treated as installable updates and improve download progress.
