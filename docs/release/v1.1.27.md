### 改进

- 选择菜单增加当前项勾选，并改善菜单边界和宽度。
- 助手配置的说明、提示与空态更简洁，支持中英日。
- 技能中的同名供应商显示域名与端口，同地址连接提供稳定编号。
- 技能层级和叠加方式显示分组名称与选中标记，支持方向键和首尾快捷键切换。

### 错误修复

- 修复技能优先级提示与基础、自适应层级的实际默认值不一致的问题。
- 修复技能层级和叠加方式未向系统提供单选状态的问题。

<summary>English</summary>

### Improvements

- Selection menus show a checkmark for the current option, with clearer boundaries and improved width.
- Assistant settings have shorter descriptions, hints, and empty states in Chinese, English, and Japanese.
- Same-name providers in skills show their host and port, with stable numbering for connections sharing the same address.
- Skill layers and stacking choices have group labels and selection markers, with arrow, Home, and End key navigation.

### Fixes

- Fixed priority hints that did not match the actual defaults for base and adaptive skill layers.
- Fixed skill layer and stacking choices missing their single-selection state in accessibility information.
