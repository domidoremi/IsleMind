# IsleMind 1.1.2

<details open>
<summary>简体中文</summary>

### 改进
- 回复过程显示活动步骤与完成状态，更容易了解处理进度。
- 改善模型页面的加载反馈，减少不必要的刷新。
- 调整 Android 明暗启动配色和液态玻璃输入框样式。

### 下载
APK 和 `.sha256` 校验文件见本页附件。
- `no-model`：不内置本地检索模型的轻量版；`with-model-small`：内置小型本地检索模型。
- `arm64-v8a`：适合多数现代 Android 手机；`universal-64`：兼容 ARM64 和 x86_64。
- `x86_64`：适合对应架构设备；`armeabi-v7a-legacy`：适合旧款 32 位 ARM 设备。

安装前请备份数据。Web 版建议使用普通浏览器窗口；隐私窗口的数据可能无法保留。

<summary>English</summary>

### Improvements
- Show activity steps and completion status so reply progress is easier to follow.
- Improve loading feedback on the model page and reduce unnecessary refreshes.
- Refine Android light and dark launch colors and liquid-glass input styling.

### Downloads
APKs and `.sha256` checksums are attached to this release.
- `no-model`: a smaller download without a local retrieval model; `with-model-small`: includes a small local retrieval model.
- `arm64-v8a`: most modern Android phones; `universal-64`: ARM64 and x86_64.
- `x86_64`: devices with that architecture; `armeabi-v7a-legacy`: older 32-bit ARM devices.

Back up your data before installing. For Web, use a regular browser window; private-window data may not persist.

<summary>日本語</summary>

### 改善
- 応答の処理ステップと完了状態を表示し、進行状況を確認しやすくしました。
- モデル画面の読み込み表示を改善し、不要な再描画を減らしました。
- Android 起動時の明暗色とリキッドガラス入力欄の表示を調整しました。

### ダウンロード
APK と `.sha256` チェックサムは本ページの添付ファイルをご確認ください。
- `no-model`：ローカル検索モデルを含まない軽量版。`with-model-small`：小型のローカル検索モデルを同梱。
- `arm64-v8a`：一般的な Android スマートフォン向け。`universal-64`：ARM64 と x86_64。
- `x86_64`：対応アーキテクチャの端末向け。`armeabi-v7a-legacy`：旧型の 32 ビット ARM 端末向け。

インストール前にデータをバックアップしてください。Web 版は通常のブラウザーウィンドウを使用してください。プライベートウィンドウではデータが保持されない場合があります。
