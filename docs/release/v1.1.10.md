# IsleMind 1.1.10

<details open>
<summary>简体中文</summary>

### 改进

- 精简粘贴文本导入区域，折叠后可查看保留草稿的字数。

### 错误修复

- 取消文件选择后安静返回资料库，不再显示失败提示。
- 修正知识文件与记忆数量的英文单复数。
- 语言切换确认使用新选择的语言。
- 修复多行正文框占位文字与标签重叠的问题，正文按高度范围显示；网页输入框在缩短或清空文本后能恢复高度。

</details>

<details>
<summary>English</summary>

### Improvements

- Simplify pasted-text import controls and show the retained draft's character count when folded.

### Bug fixes

- Return quietly to the reference library after cancelling file selection, without a failure message.
- Correct singular and plural wording for knowledge file and memory counts in English.
- Display language-change confirmations in the newly selected language.
- Fix multiline body placeholders overlapping labels and respect each field's height limits; web fields also shrink after text is shortened or cleared.

</details>
