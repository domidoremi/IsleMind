# IsleMind 1.1.0

<details open>
<summary>简体中文</summary>

### 新功能
- 新增本地 Markdown 文档库，可直接新建、编辑文档，或从已完成的回复创建文档。
- 支持为文档请求修改建议，并在应用前审阅。
- 支持从指定消息创建对话分支，保留原对话不变。
- 回复内新增来源阅读入口，可打开当前保存的知识和记忆内容。

### 改进
- 文档可随完整或按类别选择的备份导出和恢复。
- 改进多语言本地检索模型的分词，以及 Android 本地模型文件校验。
- 导出所选消息时可自行决定是否包含来源列表，敏感标题和链接会做过滤处理。
- 完善工具工作结果的记录，使执行结果和完成状态更清楚。

### 错误修复
- 修复取消回复后请求可能继续读取，或意外切换服务商目标的问题。
- 修复切换会话后旧内容或提示可能显示错位的问题。
- 修复混合检索缺少一类结果时合并不正确的问题。
- 修复引用编号或重复标识可能打开错误来源的问题。

</details>

<summary>English</summary>

### New features
- Add a local Markdown document library for creating and editing documents or saving a completed reply as a document.
- Request document revision suggestions and review them before applying changes.
- Create a conversation branch from a selected message without changing the original chat.
- Open saved knowledge and memory sources directly from citations in replies.

### Improvements
- Include documents in full or category-selective backup and restore.
- Improve tokenization for the multilingual local retrieval model and local-model file verification on Android.
- Choose whether selected-message exports include source lists, with filtering for sensitive titles and links.
- Keep more complete tool work records, making results and completion status clearer.

### Bug fixes
- Fix requests potentially continuing to read after cancellation or switching to an unintended provider target.
- Fix stale content or misplaced notices after switching conversations.
- Fix incorrect result merging when one part of hybrid retrieval is missing.
- Fix citation numbers or duplicate identifiers potentially opening the wrong source.
