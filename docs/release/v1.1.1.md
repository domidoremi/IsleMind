### 新功能
- 新增 GPT-6 Astra、Claude Fable 5.1 和 Gemini 3.8 Flash 模型。
- 新增 DeepSeek Flash、Qwen3.8 Flash 和 Cerebras qwen-3.8-27b 模型。
- 新增 GLM-5.3 Flash/FlashX、GLM-4.5 Flash 等 GLM 模型。

### 改进
- 为 Kimi K2.5、Moonshot V1 和 DeepSeek V4 Flash 等旧模型标注弃用状态并显示替代选项。
- 补全新模型的推理、图片输入和工具调用能力信息。

### 错误修复
- 修复 Cohere Command A 和 Command R 被误标为支持图片输入的问题。
- 修正 GLM-5.3 的上下文容量，调整为 100 万 Token。

<summary>English</summary>

### New features
- Add GPT-6 Astra, Claude Fable 5.1, and Gemini 3.8 Flash to the model catalog.
- Add DeepSeek Flash, Qwen3.8 Flash, and Cerebras qwen-3.8-27b to the model catalog.
- Add GLM models including GLM-5.3 Flash/FlashX and GLM-4.5 Flash.

### Improvements
- Mark older models such as Kimi K2.5, Moonshot V1, and DeepSeek V4 Flash as deprecated and show replacement options.
- Complete reasoning, image-input, and tool-calling information for the new models.

### Bug fixes
- Fix Cohere Command A and Command R incorrectly being marked as supporting image input.
- Correct the GLM-5.3 context window to one million tokens.
