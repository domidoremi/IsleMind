# IsleMind 0.0.12

<details open>
<summary>简体中文</summary>

### 新功能
- 长对话新增上一条、下一条模型回复导航，并显示当前位置。
- 模型和会话界面新增推理、搜索、工具与图片输入能力标识。
- 生成过程显示准备、思考、检索、搜索、工具调用和完成阶段。

### 改进
- 推理强度可单击切换，新增“默认”档位；不支持手动调整时会明确提示。
- 深度推理显示额外 Token 消耗和等待时间提示。
- 仅发送模型支持的采样和能力参数，减少不兼容请求。

### 错误修复
- 修复联网工具返回后最终回答可能缺失，或会话一直显示生成中的问题。

</details>

<summary>English</summary>

### New features
- Add previous and next model-reply navigation with position indicators in long chats.
- Add reasoning, search, tool, and image-input indicators to model and conversation screens.
- Show preparing, thinking, retrieval, search, tool-call, and completion stages during generation.

### Improvements
- Cycle reasoning effort with one tap, including a Default level, and show when manual adjustment is unsupported.
- Show notices about additional token use and waiting time for deep reasoning.
- Send only supported sampling and capability parameters to reduce incompatible requests.

### Bug fixes
- Fix missing final answers or chats remaining in a generating state after web-tool results.
