# IsleMind 1.1.15

<details open>
<summary>简体中文</summary>

### 改进

- 扩大聊天模型菜单关闭按钮的点击区域，更容易点中。

### 错误修复

- 模型菜单避开屏幕缺口和系统边缘，横屏时也能看到菜单内容。
- 网页聊天中，输入框有焦点时可直接点击模型按钮打开菜单。
- 网页输入区折行时保留模型按钮的焦点，关闭菜单后可从原按钮继续操作。
- 调整浏览器窗口或放大页面后，模型菜单保持在可见区域内。

</details>

<details>
<summary>English</summary>

### Improvements

- The close button in the chat model menu has a larger tap target.

### Bug fixes

- Keep the model menu clear of screen cutouts and system bars in landscape as well as portrait.
- Open the model menu with one click while the message field has focus on the web.
- Keep focus on the model button when the web composer wraps, and return to that button when the menu closes.
- Keep the model menu in view when resizing the browser window or zooming in.

</details>

<summary>日本語</summary>

### 改善

- チャットのモデルメニューを閉じるボタンのタップ領域を広げました。

### 不具合修正

- 横画面でもモデルメニューが画面の切り欠きやシステムバーに重ならないようにしました。
- Web 版でメッセージ入力欄にフォーカスがあるときも、モデルボタンを一度クリックするとメニューが開きます。
- Web 版の入力欄が折り返してもモデルボタンのフォーカスが保たれ、メニューを閉じると元のボタンに戻ります。
- ブラウザーのウィンドウサイズを変更したときやページを拡大したときも、モデルメニューが表示範囲に収まります。
