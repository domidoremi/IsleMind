# IsleMind 0.0.11

<details open>
<summary>简体中文</summary>

### 新功能
- 应用内更新显示连接、下载、校验和打开系统安装器的阶段与进度。

### 改进
- 调整聊天顶部栏间距和自动收起行为，为消息保留更稳定的阅读区域。
- 统一更新检查、下载文件选择和安装提示中的版本信息。

### 错误修复
- 修复部分服务商返回的文本工具调用无法执行的问题。
- 修复内部工具协议片段直接显示在普通回复中的问题。
- 修复本地更新清单滞后时可能漏报可安装更新的问题。

预发布版本；此标签对应的应用版本号为 `1.0.11`。本页没有安装包附件。

<details>
<summary>English</summary>

### New features
- Show connection, download, verification, and system-installer stages and progress during in-app updates.

### Improvements
- Refine chat-header spacing and automatic collapse for a more stable message viewport.
- Align version information across update checks, download selection, and installer prompts.

### Bug fixes
- Fix text-form tool calls from some providers not being executed.
- Fix internal tool-protocol fragments appearing in ordinary replies.
- Fix missed installable updates when the local update manifest is outdated.

Pre-release; the app version for this tag is `1.0.11`. No installer is attached to this release.
