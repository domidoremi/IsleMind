# IsleMind 0.0.7

<details open>
<summary>简体中文</summary>

### 新功能
- 设置中新增工作区就绪状态和可选的页面转场设置。

### 改进
- 工作过程默认收起，最终回复单独显示，改善长对话阅读。
- 精简模型、推理、提示词和工具控制，为小屏幕保留更多消息空间。
- 更新应用图标，并整理多语言项目说明入口。

### 错误修复
- 修复首次启动未正确采用系统语言或已保存语言偏好的问题。
- 修复冷启动或远端数据异常时更新检查漏报、卡住的问题。
- 修复生成、停止和错误恢复过程中的聊天界面状态异常。

</details>

<summary>English</summary>

### New features
- Add workspace-readiness status and optional page-transition settings.

### Improvements
- Collapse work details by default and display final replies separately for easier long-chat reading.
- Compact model, reasoning, prompt, and tool controls to preserve message space on small screens.
- Refresh the app icon and organize access to localized project information.

### Bug fixes
- Fix first launch not correctly using the system language or saved language preference.
- Fix missed or stuck update checks during cold starts or remote-data errors.
- Fix chat interface state issues during generation, stopping, and error recovery.

</details>
