# IsleMind 0.0.3

<details open>
<summary>简体中文</summary>

### 新功能
- 新增知识检索与本地检索模型管理，可将资料索引后用于回答。
- 新增知识、记忆、上下文、MCP、Skills 和偏好设置页面。
- 聊天新增选项面板、附件与语音操作，以及“/”命令和“@”引用入口。

### 错误修复
- 修复未配置服务商时主页打开错误页面的问题。
- 修复“/”命令和“@”引用没有结果时缺少提示的问题。
- 修复部分 Android 设备上上下文或知识检索自检失败的问题。

</details>

<details>
<summary>English</summary>

### New features
- Add knowledge retrieval and local retrieval-model management for indexing source material and using it in answers.
- Add Knowledge, Memory, Context, MCP, Skills, and Preferences screens.
- Add chat options, attachment and voice actions, and slash-command and mention entry points.

### Bug fixes
- Fix Home opening the wrong screen when no provider is configured.
- Fix missing empty-result notices for slash commands and mentions.
- Fix context or knowledge-retrieval self-check failures on some Android devices.

</details>
