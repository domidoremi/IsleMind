<summary>简体中文</summary>

### 改进

- 减少保存长会话时的重复消息写入。
- 减少处理大量供应商配置时的重复数据遍历。
- 减少发送准备阶段的重复凭据读取。

### 错误修复

- 对齐聊天参数标题与数字输入行。
- 修复发送准备期间修改访问设置或路由策略后，旧选择仍可能继续执行的问题。

<details>
<summary>English</summary>

### Improvements

- Reduce repeated message writes when saving long conversations.
- Reduce repeated data traversal when processing large provider configurations.
- Reduce repeated credential reads while preparing a reply.

### Bug fixes

- Align chat parameter labels with their numeric input rows.
- Fix outdated route selections remaining eligible after access settings or routing policies change while a reply is being prepared.

</details>

### 改善

- 長い会話の保存時に、メッセージの重複書き込みを削減しました。
- 多数のプロバイダー設定を処理する際の重複したデータ走査を削減しました。
- 返信の準備中に行われる認証情報の重複読み取りを削減しました。

### 不具合修正

- チャットパラメーターの見出しと数値入力行の位置を揃えました。
- 返信の準備中にアクセス設定やルーティング方針を変更しても、変更前の選択が引き続き実行対象になる問題を修正しました。
