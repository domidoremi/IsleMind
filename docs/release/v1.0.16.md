<summary>简体中文</summary>

### 新功能
- 自动保存各会话中未发送的草稿，离开后返回可继续编辑。
- 新增来源详情和运行修复入口，可查看引用、失败原因及恢复操作。
- 服务商设置新增用量查询配置和诊断信息。

### 改进
- 调整聊天顶部栏和输入框，让小屏幕上的模型与推理控件更紧凑。
- 更清楚地区分进行中、可重试失败、取消和结束状态，减少离开页面后的后台活动。

### 错误修复
- 修复启动失败后可能一直停留在加载页面的问题，增加明确的重试入口。
- 修复设置子页面和修复页面返回到错误位置的问题。

<summary>English</summary>

### New features
- Automatically save unsent drafts for each conversation so editing can continue after returning.
- Add source details and repair entry points for viewing citations, failure reasons, and recovery actions.
- Add usage-query configuration and diagnostic information to provider settings.

### Improvements
- Refine the chat header and composer with more compact model and reasoning controls on small screens.
- Distinguish running, retryable failure, cancelled, and ended states more clearly, with less background activity after leaving a screen.

### Bug fixes
- Fix startup failures leaving the app on the loading screen and provide a clear retry action.
- Fix nested Settings and repair screens returning to the wrong destination.

No installer is attached to this release.
