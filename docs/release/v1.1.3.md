# IsleMind 1.1.3

<details open>
<summary>简体中文</summary>

### 新功能
- 内置 Noto Sans SC、Noto Serif SC 和霞鹜文楷，中文界面随主题使用对应字体。
- 新增智能体任务入口，可选择智能体和任务类型，查看进度、预算、子任务及待确认操作。
- 新增 AI 回复举报入口，可编辑摘录、选择原因并预览后发送；需先配置接收方和隐私政策。
- 支持将聊天内容整理成文档，完成的智能体结果也可手动保存到文档。
- 新增知识导入和检索检查入口，搜索连接信息可保存后复用。
- 新增 Skill 编辑、估算单价、本地模型下载镜像和上下文压缩方式设置。
- 支持审阅模型修改建议，以及审阅或停用记忆。

### 改进
- 整理聊天和设置界面，统一导航、摘要、引用信息和任务工作区设置的呈现。
- 统一 Anthropic 和 OpenAI 的模型能力、凭据及用量处理。
- 保存文档时明确提示失败或版本冲突，避免覆盖已有修改。
- 更新简体中文、英文和日文离线指南，使说明与实际操作一致。

<summary>English</summary>

### New features
- Bundle Noto Sans SC, Noto Serif SC, and LXGWWenKai, with Chinese fonts matched to the selected theme.
- Add Agent Tasks for choosing an agent and task type, with progress, budget, child tasks, and pending actions.
- Add AI reply reporting with editable excerpts, reasons, and a preview before sending. A recipient and privacy policy must be configured first.
- Turn chat content into documents and manually save completed agent results to Documents.
- Add knowledge import and retrieval checks, with reusable saved search connections.
- Add Skill editing, estimated unit prices, local-model download mirrors, and context compression settings.
- Review model change suggestions and review or disable memories.

### Improvements
- Reorganize Chat and Settings with more consistent navigation, summaries, reference information, and task workspace settings.
- Make model capability, credential, and usage handling more consistent across Anthropic and OpenAI.
- Show document save failures and version conflicts clearly instead of overwriting existing edits.
- Update the Simplified Chinese, English, and Japanese offline guides to match the available actions.

### 新機能
- Noto Sans SC、Noto Serif SC、霞鹜文楷を同梱し、テーマに合わせた中国語フォントを使用します。
- エージェントタスクを追加しました。エージェントとタスクの種類を選び、進行状況、予算、子タスク、確認待ちの操作を確認できます。
- AI 応答の報告を追加しました。抜粋の編集、理由の選択、送信前のプレビューができます。利用には受付先とプライバシーポリシーの設定が必要です。
- 会話の内容をドキュメントに整理し、完了したエージェントの結果も手動で保存できます。
- ナレッジの取り込みと検索の確認を追加し、検索接続の設定を保存して再利用できます。
- Skill の編集、推定単価、ローカルモデルのダウンロードミラー、コンテキスト圧縮方式の設定を追加しました。
- モデル変更の提案を確認し、メモリの確認や無効化ができます。

### 改善
- チャットと設定画面を整理し、ナビゲーション、サマリー、参照情報、タスクワークスペース設定の表示を統一しました。
- Anthropic と OpenAI のモデル能力、認証情報、使用量の処理を統一しました。
- ドキュメント保存の失敗やバージョン競合を明示し、既存の編集内容の上書きを防ぎます。
- 簡体字中国語、英語、日本語のオフラインガイドを実際の操作に合わせて更新しました。
