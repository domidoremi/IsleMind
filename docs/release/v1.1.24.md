# IsleMind 1.1.24

<details open>
<summary>简体中文</summary>

### 改进

- 模型路由组与场景方案的无障碍操作名称包含序号和方案名，便于辨识同名项目。
- 扩大场景编辑按钮的最小触控范围。

### 错误修复

- 修复目录同步失败时，重叠密钥可能在错误信息中残留片段的问题。
- 修复模型路由方案保存或删除失败后，界面与已保存配置不一致的问题。
- 关闭或放弃路由编辑器后清除失效提示，保留可重试的删除错误。

</details>

<details>
<summary>English</summary>

### Improvements

- Include numbers and plan names in accessibility labels for routing and scene actions to distinguish plans with matching names.
- Increase the minimum touch area of scene editing buttons.

### Bug fixes

- Fully mask overlapping credentials in model catalog synchronization errors.
- Keep the displayed routing configuration consistent with the saved configuration after a failed save or deletion.
- Clear stale errors when closing or discarding the routing editor while retaining deletion errors that can be retried.

</details>

<details>
<summary>日本語</summary>

### 改善

- ルーティング設定とシーンの操作に番号と設定名を含め、同名の項目をアクセシビリティ上で識別できるようにしました。
- シーン編集ボタンの最小タッチ範囲を広げました。

### 不具合修正

- モデル一覧の同期エラーに重なり合うキーの一部が残る問題を修正しました。
- ルーティング設定の保存や削除に失敗した後、画面の表示と保存済みの設定が一致しない問題を修正しました。
- ルーティング編集を閉じるか破棄すると古いエラーを消し、再試行可能な削除エラーは保持します。

</details>
