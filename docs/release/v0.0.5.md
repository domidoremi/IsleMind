# IsleMind 0.0.5

<details open>
<summary>简体中文</summary>

### 新功能
- 重整聊天、会话和设置界面，采用统一的 Isle 组件与交互样式。
- 本地检索模型下载显示进度，支持镜像重试、文件校验和失败清理。
- 首页新增实验性宠物状态与动画。

### 改进
- 首页仅列出当前服务商可用模型，并改善长模型名称显示。
- 完善服务商启用、批量导入、模型同步和能力识别反馈。
- 调整推理和上下文压缩限制，对未知模型采用更保守的请求设置。

### 错误修复
- 修复流式输出卡顿、生成时未自动滚到底部和长工具调用显示异常的问题。
- 修复键盘遮挡、设置子页返回和长按删除消息的交互问题。

</details>

<summary>English</summary>

### New features
- Refresh Chat, Conversations, and Settings with unified Isle components and interaction styles.
- Show local retrieval-model download progress with mirror retries, file verification, and failure cleanup.
- Add experimental Home pet states and animation.

### Improvements
- Show only the active provider's available models on Home and improve long model names.
- Improve feedback for provider activation, bulk import, model synchronization, and capability detection.
- Refine reasoning and context-compression limits with more conservative request settings for unknown models.

### Bug fixes
- Fix choppy streaming, missing auto-scroll during generation, and long tool-call display issues.
- Fix keyboard overlap, nested Settings navigation, and long-press message deletion.
