# IsleMind 1.0.20

<details open>
<summary>简体中文</summary>

### 改进
- 减少消息气泡留白，让对话阅读更紧凑。
- 简化生成状态和思考摘要入口，移除重复装饰与输入框占位提示。
- 更新内置模型目录及请求兼容设置。

### 错误修复
- 修复服务商导入、启用或删除时重复显示通知的问题。
- 修复部分服务商图标在深色或浅色主题下难以辨认的问题。
- 修复部分新会话未使用用户设置的输出上限和温度的问题。

</details>

<details>
<summary>English</summary>

### Improvements
- Reduce message-bubble spacing for denser conversation reading.
- Simplify generation status and reasoning-summary controls, removing redundant decoration and composer placeholder text.
- Update the built-in model catalog and request compatibility settings.

### Bug fixes
- Fix duplicate notices when importing, activating, or deleting providers.
- Fix provider icons being hard to see in light or dark themes.
- Fix some new chats not using the configured output limit and temperature.

</details>
