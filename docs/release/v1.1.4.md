# IsleMind 1.1.4

<details open>
<summary>简体中文</summary>

### 新功能
- 更新提示新增“忽略本次”和“永不提醒”，关闭提醒后仍可手动检查更新。
- 设置搜索会保留上次输入，返回设置时不必重新搜索。

### 改进
- 跨多个版本更新时，更新弹窗会汇总中间版本的更新内容。
- 完善设置编辑的保存、取消和未保存提醒，切换页面时更清楚地提示待处理的改动。
- 知识和记忆的批量清理只处理确认窗口中列出的内容，保留之后新增的资料。
- 改进网页端文字行高，适配浏览器的最小字号设置。

### 错误修复
- 修复更换服务商、模型或密钥后，等待中的回复可能使用错误配置的问题。
- 修复暂停回复的状态显示和继续操作，避免重复点击继续时重复启动回复。
- 修复上一条消息发送结束后，新草稿可能被清空或输入框大小被重置的问题。
- 修复过期的保存或删除确认可能覆盖之后修改的设置、知识和记忆的问题。
- 修复部分设置读取失败被忽略的问题，启动时会明确显示错误并提供重试入口。

本次为源码更新，没有新的安装包。

</details>

<summary>English</summary>

### New features
- Update prompts now offer "Ignore this version" and "Never remind." Manual update checks remain available when reminders are disabled.
- Settings search remembers your last query, so you do not need to retype it when returning to Settings.

### Improvements
- When updating across several versions, the update dialog includes the changes from intermediate releases.
- Improve save, cancel, and unsaved-change prompts in Settings, making pending edits clearer when switching pages.
- Bulk cleanup of knowledge and memory only affects the items listed in the confirmation dialog, preserving items added afterward.
- Improve Web text line heights to accommodate the browser's minimum font size setting.

### Bug fixes
- Fix pending replies potentially using the wrong configuration after changing a provider, model, or API key.
- Fix paused-reply status and continuation actions, preventing repeated Continue clicks from starting duplicate replies.
- Fix a previous message finishing its send potentially clearing a new draft or resetting the composer size.
- Fix outdated save or delete confirmations potentially overwriting later changes to settings, knowledge, or memory.
- Fix some saved-settings read failures being ignored. Startup now displays the error and offers a retry.

This is a source update; no new installer is included.

<summary>日本語</summary>

### 新機能
- 更新通知に「今回のバージョンを無視」と「今後通知しない」を追加しました。通知を無効にしても手動で更新を確認できます。
- 設定検索が前回の入力を記憶し、設定画面に戻った際の再入力が不要になりました。

### 改善
- 複数バージョンをまとめて更新する際、更新ダイアログに途中のバージョンの変更内容も表示します。
- 設定の保存、キャンセル、未保存変更の通知を改善し、画面を切り替える際に未処理の編集内容が分かりやすくなりました。
- ナレッジとメモリの一括整理は確認ダイアログに表示された項目だけを対象とし、その後に追加された項目を保持します。
- Web の文字行高を改善し、ブラウザの最小フォントサイズ設定に対応しました。

### 不具合修正
- サービス提供者、モデル、API キーを変更した後、待機中の応答が誤った設定を使用する可能性を修正しました。
- 一時停止した応答の状態表示と継続操作を修正し、継続ボタンを繰り返し押した際の重複開始を防ぎました。
- 前のメッセージの送信完了後、新しい下書きが消えたり入力欄のサイズがリセットされたりする可能性を修正しました。
- 古い保存・削除確認が、その後に変更された設定、ナレッジ、メモリを上書きする可能性を修正しました。
- 保存済み設定の読み込み失敗が一部無視される問題を修正しました。起動時にエラーを明示し、再試行できます。

本リリースはソースの更新のみで、新しいインストーラーは含まれません。

</details>
