# IsleMind 1.1.23

<details open>
<summary>简体中文</summary>

### 改进

- 扩大背景选项的最小点击范围，改善窄屏操作。
- 精简外观设置文案，并更新岛屿主题的纯色背景说明。

### 错误修复

- 批量添加连接密钥时识别安全存储中的重复密钥，保留已有模型和健康记录。
- 结构化导入复用已有密钥组，并将首选密钥引用映射到保留组。
- 区分尚未获取的模型目录与已确认的空目录，刷新失败后保留已知模型数量。

</details>

<details>
<summary>English</summary>

### Improvements

- Increase the minimum touch area of background options for easier use on narrow screens.
- Shorten appearance settings text and update the Animal Island theme's plain background description.

### Bug fixes

- Detect credentials already in secure storage when adding keys in bulk, retaining existing model assignments and health records.
- Reuse existing credential groups during structured imports and map the preferred key reference to the retained group.
- Distinguish an unfetched model catalog from a confirmed empty catalog and retain known counts after a failed refresh.

</details>

### 改善

- 背景設定の最小タッチ範囲を広げ、狭い画面で操作しやすくしました。
- 外観設定の文言を簡潔にし、Animal Islandテーマの単色背景の説明を更新しました。

### 不具合修正

- 接続キーの一括追加時に安全なストレージ内の重複キーを識別し、既存のモデル割り当てと健全性の記録を保持します。
- 構造化データのインポート時に既存のキーグループを再利用し、優先キーの参照先を保持されたグループに対応付けます。
- 未取得のモデル一覧と取得済みの空の一覧を区別し、更新に失敗しても既知のモデル数を保持します。
