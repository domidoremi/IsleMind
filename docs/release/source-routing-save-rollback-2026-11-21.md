# 路由方案保存失败后的状态恢复

日期：2026-11-21。源码1.1.23，Android版本号148。仅源码改动。

## 修复范围

真实Web存储配额耗尽时，新建方案保存失败后仍残留在内存；用户放弃编辑后，该方案会出现在已保存列表，后续其它设置写入也会携带它。失败原件保留。

路由保存和删除改为串行处理。持久化失败时仅恢复本次修改的路由集合，保留同时修改的其它设置，并排入补偿写，修复已排队快照携带失败方案的问题。明确替换过的路由集合不会被旧操作回滚。排队前捕获输入，执行时重新校验连接；保留原始保存错误。
