# 会话路由方案变更后的配置状态刷新

日期：2026-11-17。

会话的供应商和模型不变、只修改路由方案时，聊天页现在重新读取配置状态，并丢弃旧方案尚未完成的异步结果。本次提交包含健康状态 hook 的一项依赖及三个回归用例。组成员可用性判断及其尚未提交的依赖继续在工作区验证。

基于 main 的独立源码候选复现两个旧代码失败，加入依赖后三个用例通过。既有会话配置状态与路由方案测试共七项通过，类型检查、架构边界、模块边界及依赖检查通过。检查脚本最初引用了错误的既有测试路径，未执行该套件；该失败保留，修正路径后的结果单独记录。工作区相关集成测试另有 13 组、106 项通过。

Web 与既有 Android 调试应用使用当前工作区源码验证：首选连接或密钥停用、组内其他成员可用时不显示配置异常；全部成员不可用时显示异常；恢复可用成员后清除异常。仅修改会话组成员的场景通过公开会话更新命令触发，实际挂载的聊天页及时刷新，输入控件保持同一实例。连接开关和密钥停用、保存、关闭、重开使用实际界面操作。

Web 已核对实际加载的健康检查、hook 和挂载页面的可执行源码。Android 已读取实际加载 bundle，与当前 Metro 输出逐字节比较，并核对两项源码映射和已初始化导出；该检查没有使用断点证明每次调用身份。运行验收包含工作区未提交的组功能，验收范围与本次独立提交范围分别记录。

九张 Web 健康状态图和十三张 Android 健康状态、菜单、连接开关图已查看。范围为当前中文界面与实际视口；未覆盖的主题、语言、字号、方向及无障碍组合继续保留。较早原生场景中的密钥草稿和菜单图未扩大视觉资格。
