# IsleMind 0.0.4

<details open>
<summary>简体中文</summary>

### 改进
- 改善 Android 本地检索库的 16 KB 内存页兼容性，减少相关警告。
- 完善服务商导入或新建后的启用进度和失败提示。
- 优化键盘避让、输入框快捷操作和模型选择面板。

### 错误修复
- 修复上下文容量、输出上限和压缩限制可能超出模型能力的问题。
- 修复新服务商可能继承旧配置中不可用默认模型的问题。

预发布版本；此标签对应的应用版本号为 `1.0.4`。本页没有安装包附件。

<summary>English</summary>

### Improvements
- Improve 16 KB memory-page compatibility for Android local retrieval libraries and reduce related warnings.
- Improve activation progress and failure notices after importing or creating providers.
- Improve keyboard avoidance, composer shortcuts, and the model picker.

### Bug fixes
- Fix context, output, and compression limits potentially exceeding model capabilities.
- Fix new providers potentially inheriting an unavailable default model from older settings.

Pre-release; the app version for this tag is `1.0.4`. No installer is attached to this release.
