# IsleMind 1.1.7

<details open>
<summary>简体中文</summary>

### 新功能
- 文档库支持按更新时间或标题排序，返回列表后保留搜索、排序与滚动位置。
- 宽屏文档编辑和来源阅读增加辅助上下文区域，小屏、横屏与大字体下自动调整布局。
- 消息操作新增键盘可用入口，可用 Tab、Enter 或空格打开菜单，关闭后回到原按钮。

### 改进
- 首次连接页面按当前任务提供配置入口，模型选择、连接状态与下一步操作更清晰。
- 编辑与预览共用已挂载的文档输入区，切换时保留草稿、选区和阅读位置。
- 来源导航明确显示当前引用，保留已经取得的来源快照与返回位置。
- 设置导航、连接卡片和使用统计详情采用更清晰的层级与留白，改善窄屏和大字体下的阅读。
- 协调五种主题的背景、边界、按压与焦点反馈，并改善键盘出现时的滚动和输入可见性。
- 举报暂不可用时，直接在消息操作入口显示当前状态。
- 补齐中文、英文和日文界面文案。

### 错误修复
- 修复停留在设置或历史页面后，再次打开首页深链仍未切回首页的问题，并保留首页草稿。
- 修复服务商认证失败被显示为通用发送失败的问题；现在提供具体密钥或权限指引，并保留已生成的部分回答。
- 修复消息菜单打开及进入更多操作时的键盘焦点，以及关闭后的焦点恢复。
- 修复偏好页固定展开标题被错误标记为禁用、文字对比度过低的问题。
- 修复部分 Android 视图复用时的边框间距残留，以及部分主题操作反馈和来源定位不稳定的问题。

</details>

<summary>English</summary>

### New features
- Sort the document library by update time or title, retaining search, sorting, and scroll position when returning.
- Use supporting context areas alongside document editing and source reading on wide screens, with layouts that adapt to small screens, landscape windows, and larger text.
- Open message actions with Tab, Enter, or Space, and return focus to the opener when the menu closes.

### Improvements
- Provide task-based configuration entry points during initial connection setup, with clearer model choices, connection status, and next steps.
- Keep the document input mounted across editing and preview, preserving drafts, selection, and reading position.
- Identify the selected citation in source navigation and retain fetched source snapshots and the return position.
- Improve hierarchy and spacing in settings navigation, connection cards, and usage details for narrow screens and larger text.
- Coordinate backgrounds, boundaries, press feedback, and focus across all five themes, and improve scrolling and input visibility when the keyboard appears.
- Label reporting availability directly in message actions when reporting is unavailable.
- Complete missing Chinese, English, and Japanese interface text.

### Bug fixes
- Fix repeated Home deep links failing to return from retained Settings or History pages, while preserving the Home draft.
- Fix provider authentication failures appearing as generic send failures; show specific key or permission guidance and retain partial responses.
- Fix keyboard focus when opening message menus, entering more actions, and returning to the opener.
- Fix pinned preference headings being marked as disabled and rendered with insufficient contrast.
- Fix stale border insets when some Android views are reused, along with unstable action feedback and source positioning in some themes.

<summary>日本語</summary>

### 新機能
- 文書一覧を更新日時またはタイトルで並べ替えられます。一覧に戻った際も検索、並び順、スクロール位置を保持します。
- 広い画面では文書編集と参照元の閲覧に補助コンテキスト領域を表示し、小さい画面、横向き、大きな文字にも配置を調整します。
- Tab、Enter、スペースでメッセージ操作を開き、メニューを閉じると元のボタンにフォーカスを戻します。

### 改善
- 初回接続時に目的に応じた設定入口を表示し、モデル選択、接続状態、次の操作を分かりやすくしました。
- 編集とプレビューで文書入力欄を保持し、切り替え時も下書き、選択範囲、読書位置を維持します。
- 参照元のナビゲーションで選択中の引用を明示し、取得済みのスナップショットと戻り位置を保持します。
- 設定ナビゲーション、接続カード、使用統計の詳細の階層と余白を整え、狭い画面や大きな文字でも読みやすくしました。
- 五つのテーマの背景、境界、押下とフォーカスの表示を整え、キーボード表示時のスクロールと入力欄の見え方を改善しました。
- 通報を利用できない場合は、メッセージ操作の入口に現在の状態を表示します。
- 中国語、英語、日本語の不足していた画面文言を補いました。

### 不具合修正
- 設定や履歴の画面を保持した状態でホームへのディープリンクを再度開いても戻れない問題を修正し、ホームの下書きを保持します。
- プロバイダーの認証エラーが一般的な送信失敗になる問題を修正しました。キーや権限の具体的な案内を表示し、生成途中の回答も保持します。
- メッセージメニューを開く時、追加操作に移る時、閉じて元のボタンに戻る時のキーボードフォーカスを修正しました。
- 常に開く設定見出しが無効と表示され、文字のコントラストが不足する問題を修正しました。
- 一部の Android ビュー再利用時に境界の余白が残る問題と、一部テーマで操作表示や参照元の位置が不安定になる問題を修正しました。
