# 合并全部费用未知时的重复提示

回复回执、请求详情和复制摘要共用费用格式化函数。所有尝试均未报告费用时，原界面同时显示“费用未报告”和“1 次费用未知”。现在仅显示一次费用未报告；已报告的零费用仍显示金额，部分费用已知时继续列出已知小计和未知次数，数值溢出及未知次数保持独立。

日文和英文浅色 Android 截图中均可见原重复提示，见[行内重试检查点](../../test-evidence/implementation/native-routing-groups-20261115-01/native-inline-retry-checkpoint-20261120-1470.json)。本次修复限定源码和自动回归，设备仍加载第37份源码，不把修复前截图记为修复后的原生验收。

新增三语21项回归使用实际语言资源和用量聚合结果，覆盖全部未知、真实零值、部分未知、溢出和空历史。修复前主线和工作区各9项失败、12项通过；修复后独立主线四组36项、工作区五组43项，以及各自类型和架构检查通过，计数不相加。扩大主线检查时误列一个仅工作区存在的界面测试，ENOENT失败保留；确认文件归属后分别运行实际测试集，见[最终回归记录](../../test-evidence/implementation/native-routing-groups-20261115-01/usage-cost-validation-20261120-1474.json)。
