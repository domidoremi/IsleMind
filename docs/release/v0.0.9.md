# IsleMind 0.0.9

<details open>
<summary>简体中文</summary>

### 新功能
- 长对话和超长消息新增上下文压缩状态，显示触发原因与节省量。
- 新增服务商连接、压缩、代理和日志诊断信息。
- 新增卡通、玻璃和极简主题，改善颜色对比度与图标一致性。
- JSON、CSV 和 TSV 内容显示类型、条目与字段摘要。

### 改进
- 联网搜索仅在服务商返回来源时显示来源支撑标记。
- 服务商列表支持拖动或按钮排序，批量启用限制同时处理的数量。
- 更清楚地区分网络、鉴权、模型和协议错误，并补充 Azure、Vertex AI 和 Bedrock 的能力提示。
- 自定义服务商地址增加校验，清空全部服务商时提示密钥会被删除。
- 数据导出后可通过系统分享交付文件。

</details>

<summary>English</summary>

### New features
- Show context compression states for long chats and oversized messages, including trigger reasons and savings.
- Add provider connection, compression, proxy, and log diagnostics.
- Add Cartoon, Glass, and Minimal themes with improved contrast and icon consistency.
- Show type, item, and field summaries for JSON, CSV, and TSV content.

### Improvements
- Mark web-search answers as source-backed only when the provider returns sources.
- Order providers by dragging or buttons, and limit simultaneous bulk activations.
- Distinguish network, authentication, model, and protocol errors, with clearer capability notices for Azure, Vertex AI, and Bedrock.
- Validate custom provider addresses and warn that clearing all providers deletes saved keys.
- Share exported data through the system share sheet.
