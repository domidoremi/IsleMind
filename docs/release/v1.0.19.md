# IsleMind 1.0.19

<details open>
<summary>简体中文</summary>

### 新功能
- 长草稿可在紧凑、审阅和大编辑器之间切换，也可手动展开或折叠。
- 新增撤销、重做和 Markdown 编辑工具，支持复制全文，清空前会先确认。
- 新增“跳到最新消息”入口，方便在长对话中返回底部。

### 改进
- 更清楚地显示中断任务是否可以继续、取消或已经结束。
- 优化长文本、多语言消息和浮动输入框布局。

### 错误修复
- 修复普通聊天交接时可能出现重复保存或回复未保存的问题。
- 修复 Android 和 iOS 键盘可能遮挡输入框或造成跳动的问题。

</details>

<summary>English</summary>

### New features
- Switch long drafts between compact, review, and large editor modes, with manual expand and collapse controls.
- Add undo, redo, and Markdown editing tools, with copy-all and confirmation before clearing text.
- Add a jump-to-latest control for returning to the bottom of long conversations.

### Improvements
- Make it clearer whether interrupted tasks can continue, can be cancelled, or have ended.
- Improve layouts for long text, multilingual messages, and the floating composer.

### Bug fixes
- Fix duplicate saves or unsaved replies during ordinary chat handoff.
- Fix the Android and iOS keyboards potentially covering the composer or causing layout jumps.
