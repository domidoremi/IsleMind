# 连接详情导入模型选择维护记录

连接详情保存时保留导入配置明确指定的模型选择，包括空列表和部分选择。导入之后手工添加的模型或别名继续自动启用，未选择的导入模型保持停用。重开、取消编辑、重复导入、保存后继续编辑及持久化失败重试均重建对应基线，避免旧的停用模型被误判为新增项。

主线候选补齐详情表单的选择状态、导入、重置和保存；工作区只加入选择基线，保留原有界面与健康状态修复。最终正式目录下主线 5 组 74 项、工作区 5 组 100 项通过，两者完整类型检查和架构边界检查通过。22 项新增回归使用真实组件、store、配置解析与持久化绑定，包含保存排队期间的健康更新和真实配置冲突；平台存储采用内存适配器，测试禁止网络请求。
