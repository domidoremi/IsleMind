# IsleMind 1.0.23

<details open>
<summary>简体中文</summary>

### 新功能
- 新增上下文容量面板，可查看最近一次请求的估算占用、限制和提示。
- 新增“使用当前模型压缩上下文”选项，显示压缩进度及额外调用费用提示。

### 改进
- 改进知识检索与结果排序，未命中或使用回退方案时给出更清楚的说明。
- 增加主题背景效果，调整聊天、设置、服务商和 MCP 页面。

### 错误修复
- 修复新会话和主页入口未继承用户输出上限与温度设置的问题。
- 修复宽屏下消息正文与输入框不在同一阅读列的问题。
- 修复同一会话可能重复压缩上下文，或过早显示完成状态的问题。

</details>

<summary>English</summary>

### New features
- Add a context-capacity panel showing estimated usage, limits, and notices for the latest request.
- Add an option to compress context with the current model, with progress and a notice about additional provider charges.

### Improvements
- Improve knowledge retrieval and result ranking, with clearer notices for missing results and fallback behavior.
- Add themed background effects and refine Chat, Settings, Providers, and MCP screens.

### Bug fixes
- Fix new chats and Home entry points not inheriting the user's output-limit and temperature settings.
- Fix messages and the composer appearing in separate reading columns on wide screens.
- Fix overlapping context compression or premature completion status in the same conversation.
