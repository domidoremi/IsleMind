### 界面与主题

- 输入框标签沿用各主题的字体与文字层级。
- 列表标题、描述和辅助说明采用主题排版。
- 输入字段的标题与说明同步主题字号、行高和字重。
- 引用选择字段的标题、已选内容及手动入口使用对应的主题文字样式。
- 下拉选择器的选中值、占位文字与选项统一主题排版，Web 行高适配浏览器文字缩放。

### 更新说明

共用输入、列表与选择控件在明暗模式下延续各自的主题文字风格。

### Interface and themes

- Input labels use each theme's fonts and text hierarchy.
- List titles, descriptions, and supporting text use theme typography.
- Field titles and descriptions follow theme font sizes, line heights, and weights.
- Reference field titles, selected content, and manual entry actions use their theme text styles.
- Select values, placeholders, and options use theme typography, with Web line heights that accommodate browser text scaling.

### Update notes

Shared input, list, and selection controls retain their theme text styles in light and dark modes.

### インターフェースとテーマ

- 入力欄のラベルに各テーマのフォントと文字階層を適用します。
- リストの見出し、説明、補足文にテーマの文字スタイルを適用します。
- 入力フィールドの見出しと説明をテーマの文字サイズ、行高、太さに合わせます。
- 参照選択欄の見出し、選択済みの内容、手動入力ボタンに対応するテーマの文字スタイルを適用します。
- 選択メニューの値、プレースホルダー、選択肢をテーマの文字スタイルに統一し、Web の行高をブラウザーの文字拡大に対応させます。

### 更新内容

共通の入力、リスト、選択コントロールで、明るい表示と暗い表示の両方にテーマの文字スタイルを適用します。
