# IsleMind 1.0.22

<details open>
<summary>简体中文</summary>

### 新功能
- 新增按类别选择的备份与恢复，可单独选择需要导出或导入的数据。
- 扩展用量统计和价格信息，便于查看不同服务商与模型的使用情况。
- 新增项目网站源码与产品截图。

### 改进
- 统一聊天、设置和通知的主题样式，改善不同主题下的可读性。
- 改进服务商能力识别、请求兼容和故障切换。

### 错误修复
- 修复部分错误提示未使用当前应用语言的问题。
- 修复聊天滚动、键盘联动、浮动输入框和长对话导航中的布局问题。

本页没有安装包附件。

<details>
<summary>English</summary>

### New features
- Add category-selective backup and restore for choosing which data to export or import.
- Expand usage statistics and pricing information for comparing providers and models.
- Add project website source files and product screenshots.

### Improvements
- Unify themed styling across Chat, Settings, and notices for better readability.
- Improve provider capability detection, request compatibility, and failover.

### Bug fixes
- Fix some error messages not using the selected app language.
- Fix layout issues with chat scrolling, keyboard interaction, the floating composer, and long-conversation navigation.

No installer is attached to this release.
