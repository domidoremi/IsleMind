# IsleMind 1.1.22

<details open>
<summary>简体中文</summary>

### 改进

- 岛屿主题使用明暗模式对应的纯色画布，移除全屏装饰并隐藏无效果的背景选项。

### 错误修复

- 窄屏连接标题独立成行，避免被操作按钮挤压，并保留完整无障碍名称。
- 同名密钥的更换控件使用序号和名称区分，提供展开状态及独立的密码框名称。
- 同步网页外观模式标记，避免切换后仍保留启动时的偏好。

</details>

<details>
<summary>English</summary>

### Improvements

- Use a plain light or dark canvas for the Animal Island theme, remove full-screen decoration, and hide inactive background options.

### Bug fixes

- Give narrow connection titles their own row so action buttons do not squeeze them, while preserving the full accessible name.
- Distinguish replacement controls for credentials with identical names by position and name, and expose their expanded state and password field name.
- Synchronize Web appearance mode metadata so it no longer retains the startup preference after switching modes.

</details>

<details>
<summary>日本語</summary>

### 改善

- Animal Islandテーマに明暗モードに応じた単色の背景を使用し、全画面の装飾と効果のない背景設定を取り除きました。

### 不具合修正

- 狭い画面では接続名を独立した行に配置し、操作ボタンによる圧迫を防ぎながら完全なアクセシブル名を保持します。
- 同名の認証情報の変更操作を番号と名前で区別し、展開状態とパスワード入力欄の名前を提供します。
- Webの外観モード属性を同期し、モード切り替え後も起動時の設定が残る問題を修正しました。

</details>
