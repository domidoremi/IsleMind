# 模型菜单关闭按钮

输入区模型菜单的关闭按钮从 36×36 扩大到 44×44。标题行同步增加高度，关闭图标保持原尺寸。

五个主题的深浅色共十项回归在原实现上均测得 36。修改后，工作区三套 64 项测试及独立提交候选两套 37 项测试通过。

Web 在 320×640、900×420、1280×900 三个初始视口分别启动。中英日、五主题及深浅色共 90 个组合均测得 44×44 CSS 像素。在距离四条边各 2 像素的位置命中同一按钮，通过右侧命中元素的 DOM 点击关闭菜单。横屏与桌面两次遇到 SQLite 文件占用，点击启动页的“重试”后恢复。每种尺寸完成后，13 项原始存储值、六个文件共 815104 字节、当前页面会话标识和 70 条请求日志均与基线一致。

既有 Android 隔离安装在中文岛屿深色主题下实测 121×121 物理像素，屏幕密度 440 dpi，对应 44×44 dp。实际点按右缘内约 2 dp 后菜单关闭。已查看打开与关闭的两张截图，关闭图标完整，关闭后返回原会话。操作前后 53 张表、四项原始存储、六组草稿与恢复槽、编辑器、现有路由和 USB 设置前台通过核对。

定向重载后的真机脚本共 26756167 字节，与当前 Metro 响应一致。1180 份项目文本、三份字体和三种已初始化的语言资源通过比对。实际挂载的菜单、输入区、消息列表、消息项、气泡及用量回执与当前源码对应。

Web 本轮的可信鼠标、键盘和动画帧未到达页面。连续改变视口后有两次横屏菜单上缘超出视口，固定尺寸重新加载后的检查通过。保留启动锁冲突、640 像素布局切换时的键盘焦点丢失、历史导航实例及旧外部任务的恢复限制。全应用功能、视觉及运行源码整体验收仍在进行。
