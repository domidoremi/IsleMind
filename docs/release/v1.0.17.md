# IsleMind 1.0.17

<details open>
<summary>简体中文</summary>

### 新功能
- 新增极简、莫奈、Material 3 和液态玻璃四套主题，均支持浅色与深色外观。
- 支持跟随系统外观、自定义强调色和透明效果，并保存外观选择。

### 改进
- 将旧版主题选择映射到新的主题，尽量保留原有外观偏好。

### 错误修复
- 修复网页端启动时先显示默认颜色、再切换主题的闪烁问题。
- 修复页面切换后键盘或无障碍焦点可能停留在旧页面的问题。

本页没有安装包附件。

<summary>English</summary>

### New features
- Add Minimal, Monet, Material 3, and Liquid Glass themes, each with light and dark appearances.
- Follow system appearance, customize the accent color and transparency, and retain appearance preferences.

### Improvements
- Map older theme choices to the new themes to preserve appearance preferences where possible.

### Bug fixes
- Fix the Web app flashing default colors before applying the saved theme.
- Fix keyboard or accessibility focus remaining on the previous screen after navigation.

No installer is attached to this release.
