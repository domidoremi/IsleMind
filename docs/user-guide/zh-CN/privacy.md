# 数据与隐私

<a id="goal"></a>
## 完成什么

安全备份、恢复并理解数据边界。

<a id="steps"></a>
## 操作步骤

![选择、配置、确认的三步流程](../assets/setup-flow.svg)

1. 进入备份与恢复，选择导出类别并阅读敏感信息提示。

2. 恢复前检查范围、数量、差异；不确定时先备份。

3. 访问、代理和日志在专门入口修改；清除或重置前确认目标。

<a id="success"></a>
## 成功表现

保管好导出文件；以实际结果判断恢复成功。

<a id="troubleshooting"></a>
## 常见问题

不要公开上传备份或完整日志；端末数据删除不删除服务商副本。

<a id="advanced-policy"></a>
## 高级配置的保存边界

代理地址、日志限制和访问列表等文本字段需要显式保存。失焦、收起高级区域或阅读手册不会提交；有草稿时页面会显示未保存入口。重新加载会放弃该字段的输入，读取已提交值。

连接目标、访问规则和日志外发会改变数据边界，不提供通用撤销。启用外部日志前核对目标与脱敏范围；费用未知不代表免费。配置保存失败时输入仍保留，但个别存储写入可能已经完成，不保证跨凭据的原子回滚。

<a id="content-reporting"></a>
## 举报 AI 回复

从 AI 回复的更多菜单进入举报，先编辑摘录、选择原因和填写可选备注，再预览并明确发送。发送前核对接收方与隐私政策，手动删除密钥及个人信息；自动脱敏不能保证发现全部敏感内容。举报包包含摘录、原因、备注、举报 ID、应用版本和格式版本，不自动附带完整会话、附件、服务商凭据或内部追踪。接收端仍可能处理 IP 等连接信息。

运营接收方或隐私政策未配置时不能发送。收到回执只表示接收，不代表审核或处置完成。离页、进入后台或停止等待会取消本机等待，但不能撤回接收端可能已收到的举报；失败或超时也不能证明未送达。需要重试时先核对界面，不要反复创建同一举报。
