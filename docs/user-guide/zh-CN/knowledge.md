# 知识与记忆

<a id="goal"></a>
## 完成什么

导入资料并审阅长期记忆。

<a id="steps"></a>
## 操作步骤

![选择、配置、确认的三步流程](../assets/setup-flow.svg)

1. 进入知识与联网 → 知识库，选择资料，查看解析与索引进度。

2. 检查内容和筛选条件，返回聊天验证相关引用。

3. 进入记忆审核待处理项，只批准正确且适合保留的信息。

<a id="success"></a>
## 成功表现

完成索引的资料可供检索；已批准记忆按当前策略使用。

<a id="troubleshooting"></a>
## 常见问题

导入失败检查格式、容量和模型依赖。拒绝记忆不等于删除源文件。
