# 用量与费用

<a id="goal"></a>
## 完成什么

区分使用记录与服务商账单。

<a id="steps"></a>
## 操作步骤

![选择、配置、确认的三步流程](../assets/setup-flow.svg)

1. 进入模型与回答 → 用量，选择时间与范围。

2. 核对请求数和 Token，注意失败、取消与缺失记录。

3. 估算或未知费用以服务商账单为准；未知不是免费。

<a id="success"></a>
## 成功表现

指标用于比较趋势，不能替代计费系统。

<a id="troubleshooting"></a>
## 常见问题

核对时区、单价、记录范围；删除本地记录不取消已有费用。

<a id="pricing-overrides"></a>
## 设置估算单价

1. 在用量页找到「自定义价格」，选择添加或编辑已有项。
2. 核对服务商和模型，按「每百万 Token」分别填写输入与输出单价。界面使用美元；这只影响应用内估算，不会更改服务商定价。
3. 点击保存，等待表单关闭。负数、非数字和超过支持范围的数值不能保存。

输入内容仅保留在当前编辑页。失焦或查看使用手册不会保存；关闭和返回时可继续编辑或放弃更改，点击取消会直接丢弃草稿。保存期间不能重复提交或关闭表单。

保存失败会显示错误并保留输入，可修正后重试。如果价格已被其他编辑或备份恢复修改，先重新加载最新值，再决定如何修改。未知费用仍应核对服务商账单，不要填入零来消除未知提示。
