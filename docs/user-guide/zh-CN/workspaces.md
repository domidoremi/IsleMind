# 工作区与角色内容

<a id="goal"></a>
## 完成什么

按场景管理独立内容与角色资料。

<a id="steps"></a>
## 操作步骤

![选择、配置、确认的三步流程](../assets/setup-flow.svg)

1. 选择工作区，确认会话和角色。

2. 导入前检查来源、权限、内容，先在测试会话验证。

3. 角色、场景和关系记忆的待写入内容先审阅再批准。

<a id="success"></a>
## 成功表现

内容按当前场景使用；待审核草稿不是已生效资料。

<a id="troubleshooting"></a>
## 常见问题

恢复前检查备份范围。私密和待写入项目可能有单独导出限制，须阅读警告。
