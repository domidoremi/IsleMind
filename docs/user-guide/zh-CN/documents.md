# 文档

<a id="goal"></a>
## 完成什么

整理并保存需要继续编辑的内容。

<a id="steps"></a>
## 操作步骤

![选择、配置、确认的三步流程](../assets/setup-flow.svg)

1. 在文档列表新建或打开文档。

2. 编辑标题和正文，预览后保存。

3. 发生版本冲突先重新加载或保留副本，不覆盖新内容。

<a id="success"></a>
## 成功表现

保存后可重新打开；未保存输入不是备份。

<a id="troubleshooting"></a>
## 常见问题

保存失败应保留输入并检查错误；分享前检查隐私和凭据。

<a id="save-and-reuse"></a>
## 从聊天整理成文档

从文档列表新建空白文档，或将已结束的助手回复保存为文档草稿。先检查标题和正文，再点击保存；打开草稿或切换预览都不等于保存成功。

文档是独立副本：编辑文档不会重写聊天，删除聊天也不会删除已经保存的文档。由回复创建的文档可查看来源与当时状态；来源说明不代表回答已经核实，也不代表相关任务成功。

预览不会自动加载远程图片。复制正文只复制文本，不包含附加的来源记录。复制、分享或打开外部链接前，检查是否包含私人资料。

<a id="review-revisions"></a>
## 审阅模型修改建议

1. 展开修改建议，选择可用模型并填写具体要求。生成会调用所选服务商，可能产生费用。
2. 若需参考来源，先读取并检查当前内容，再选择是否加入本次请求。来源可能已在原回答之后更新。
3. 对比原文与建议，核对事实、遗漏和引用。点击接受只改变当前草稿，仍需单独保存。
4. 只有明确选择连同审阅资料一起接受，才将该次选用的来源快照附到草稿。普通接受不额外保留这些来源副本。

离页或进入后台会取消正在进行的建议生成。建议过期、文档被其他操作修改时，重新检查当前版本后再生成；不要用旧建议覆盖新内容。

<a id="save-conflicts"></a>
## 保存失败或版本冲突

保存失败时保留当前输入，检查错误后重试。出现版本冲突时，「重新加载」会读取最新保存版本并放弃本地修改；「保存副本」保留当前内容为独立文档。先决定要保留哪份内容，再选择操作。

未保存草稿不会在进程终止后自动恢复。文档保存与[数据备份](privacy.md#steps)是不同操作，不要把一次保存当作设备之外的备份。
