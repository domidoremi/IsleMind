# 文档

<a id="goal"></a>
## 完成什么

整理并保存需要继续编辑的内容。

<a id="steps"></a>
## 操作步骤

![选择、配置、确认的三步流程](../assets/setup-flow.svg)

1. 在文档列表新建或打开文档。

2. 编辑标题和正文，预览后保存。

3. 发生版本冲突先重新加载或保留副本，不覆盖新内容。

<a id="success"></a>
## 成功表现

保存后可重新打开；未保存输入不是备份。

<a id="troubleshooting"></a>
## 常见问题

保存失败应保留输入并检查错误；分享前检查隐私和凭据。
