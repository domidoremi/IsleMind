# 模型与回答

<a id="goal"></a>
## 完成什么

配置服务商连接与生成参数。

<a id="steps"></a>
## 操作步骤

![选择、配置、确认的三步流程](../assets/setup-flow.svg)

1. 选择服务商，再填写连接信息。自定义地址应为 API 基础地址，而非登录网页。

2. 填写凭据和模型，检查后保存。查看手册不会提交草稿；离开时可继续编辑或放弃。

3. 生成参数选模型默认，或按需要指定温度、输出上限。

<a id="success"></a>
## 成功表现

其他页面只读取已提交值。保存成功不代表连通或免费。

<a id="troubleshooting"></a>
## 常见问题

401/403 检查凭据与权限；404 检查地址、协议、模型名。截图须隐藏密钥。

<a id="generation"></a>
## 生成参数

- **模型默认**：不发送该项自定义值，由模型和服务商处理；它不是统一固定数值。
- **自定义**：使用滑杆预览、加减按钮或精确输入。滑杆松手才提交；取消手势不会写入。精确输入完成后沿用原有范围校验。
- 温度影响采样，不保证事实正确；更大的输出上限可能增加用量，模型仍可能使用更低的实际限制。
- 已提交偏好可撤销；若其他操作已修改同一字段，撤销不会覆盖较新的值。

<a id="editing"></a>
## 连接草稿与保存失败

打开已有服务商直接编辑连接、凭据和模型，不必重走新建流程。使用说明在当前编辑器上方打开，不会保存草稿。返回或关闭编辑器时，选择继续编辑或放弃更改。

只有持久化完成才提示已保存。失败时保留输入并重试；如果提示外部配置已变化，先放弃当前草稿并重新打开，不要用旧页面覆盖新配置。保存不自动测试或启用服务商；模型测试和用量查询是单独的显式操作，可能访问服务商或计费。
