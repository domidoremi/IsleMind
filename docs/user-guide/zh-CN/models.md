# 模型与回答

<a id="goal"></a>
## 完成什么

配置服务商连接与生成参数。

<a id="steps"></a>
## 操作步骤

![选择、配置、确认的三步流程](../assets/setup-flow.svg)

1. 在服务商列表点「添加」，选择导入配置或手动添加。导入先在本地核对名称、地址、模型及脱敏凭据摘要；重复连接可跳过或另存，已有配置不会被覆盖。

2. 保存后进入模型页，选择用于新对话的模型。没有模型时可手工填写模型 ID；不要求先测活。

3. 日常切换从首页的模型选择器完成。连接页可改名、改地址和更换凭据，高级参数与批量管理只在需要时打开。

<a id="success"></a>
## 成功表现

其他页面只读取已提交值。保存成功不代表连通或免费。

<a id="troubleshooting"></a>
## 常见问题

401/403 检查凭据与权限；404 检查地址、协议、模型名。截图须隐藏密钥。

<a id="generation"></a>
## 生成参数

- **模型默认**：不发送该项自定义值，由模型和服务商处理；它不是统一固定数值。
- **自定义**：使用滑杆预览、加减按钮或精确输入。滑杆松手才提交；取消手势不会写入。精确输入需要点击保存，沿用原有范围校验；失焦、折叠和阅读手册均不提交。
- 有未保存的精确输入时，先保存或重新加载已保存值，再操作滑杆、步进或默认值切换，避免覆盖草稿。工作流数值和助手名称也使用显式保存。
- 温度影响采样，不保证事实正确；更大的输出上限可能增加用量，模型仍可能使用更低的实际限制。
- 已提交偏好可撤销；若其他操作已修改同一字段，撤销不会覆盖较新的值。

<a id="editing"></a>
## 连接草稿与保存失败

连接、凭据、模型共用一份草稿；切换页签不丢输入。更换凭据时默认隐藏输入，留空保留旧凭据，点击保存才提交。保存失败保留草稿；配置已被其他操作修改时，需重新打开核对，不能用旧页面覆盖新值。保存与选择模型都不触发测活。选择成功只代表本地偏好已持久化，不表示网络连接成功，也不改已有对话。

导入先核对再保存，不再询问「全部启用并检测」。已提交但落盘失败时可以重试，不重复添加、不回退后续修改；关闭不会撤销已经提交的数据。尚未保存的输入在明确放弃后清除。

获取模型列表、手动用量查询都是独立网络操作，不随页面打开或保存自动运行。用量配置保存后才能手动查询，每次最多一次请求，并显示实际返回的数值。历史失败仍保留为提示，不把网络错误当作凭据无效，也不靠重新测活才能选择模型。

在连接页展开「连接引用」，查看哪些会话、路由、场景和模型偏好使用这个连接，以及它承担当前模型、首选或备用的哪种角色。点击引用可打开对应配置；这一步只读取本机配置，不会测试模型。报告显示读取时点，刷新可查看后续变化。保存会话的未检查范围和无法读取的配置单独标明，本地未发送草稿也会计入。

删除供应商组、全部连接或无效连接前，确认窗口会补充引用数量与检查范围；读取失败可重试，本次不会删除连接。删除会调整受影响的默认连接并移除该连接的收藏；路由、场景、会话及最近模型选择仍保留原引用，需要时再明确选择其他模型。已有消息和执行记录保留。

<a id="routing"></a>
## 路由方案

从模型设置或连接管理进入「路由方案」，保存固定模型或「首选 + 一个备用」方案。每个目标都绑定准确的连接与模型 ID；显示名只帮助识别。预览会说明首选、备用和跨连接询问方式，保存方案不会发送测试请求。

在对话的模型选择器里选用方案后，对话保存一份副本。编辑或删除管理页中的方案不会悄悄改变已选用的对话；重新选用才应用新版。使用另一个连接作为备用时默认每次询问，允许自动切换需要明确选择；已有能力、凭据、取消与工具连续性限制仍会检查。

从回复回执进入请求详情，可以查看实际尝试的连接与模型、改道结果及用量来源。供应商没有报告的实际上游和数据会显示未知。更多读法见[请求与用量](usage.md)。

<a id="scenes"></a>
## 场景方案

从设置进入「场景方案」，把研究、写作等常用配置保存为有名称的方案。完整 AI 配置中的「保存为方案」可以复制当前会话配置；「选择方案」可以打开已有方案。编辑分为会话、资源与上下文三个页签，点击保存后才能选用。

每个字段都可以选择「保留当前」。资源选择「不选用」会关闭目标会话的对应工具或知识范围；选择「指定」需至少选一项。上下文阈值和工具声明模式可以「跟随全局」，也可以只为该会话指定。技能变量使用类型与默认值，必填项需要补全。工具范围、权限与能力开关仍分别生效，供应商内置搜索和记忆在上下文设置中单独管理。

先选目标会话或新会话，再点击「应用预览」，核对准确连接、模型、首选和备用、跨连接规则及配置前后值。缺失引用、访问限制、无效技能变量或运行中的会话会阻止应用；预览后配置发生变化，需要刷新预览。保存失败保留草稿，可以重试；模板冲突时可以重新加载或另存为新方案。

点击应用后，已有会话保存一份独立配置副本，历史消息保留原内容。新会话只创建未发送草稿，第一条消息仍需你主动发送。预览、保存和应用都不会测试供应商，也不会自动发送技能中的第一条消息。修改或删除方案不改变已经应用的会话；「上次应用」记录来源，不代表会话持续跟随模板。技能、工具和知识定义仍来自各自当前目录，后续需要新版配置时重新预览并应用。
