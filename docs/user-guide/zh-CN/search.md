# 联网与检索

<a id="goal"></a>
## 完成什么

为问题选择检索范围。

<a id="steps"></a>
## 操作步骤

![选择、配置、确认的三步流程](../assets/setup-flow.svg)

1. 进入知识与联网 → 上下文。

2. 选择现有快速、均衡、深入或离线方案，检查所需模型和服务。

3. 用需要资料的问题验证，核对来源而不只看回答长度。

<a id="success"></a>
## 成功表现

使用方案允许的知识和搜索结果。离线检索不等于整个应用禁网。

<a id="troubleshooting"></a>
## 常见问题

无结果时检查索引、搜索服务及访问限制。更多资料不保证更正确。
