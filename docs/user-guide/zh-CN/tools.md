# 工具与自动化

<a id="agent-tasks"></a>
## 智能体任务

在设置 → 工具与自动化 → 智能体中创建定义，再从会话选项打开「智能体任务」，选择
智能体和任务类型。普通聊天不会额外请求独立评审；没有可靠行动能力的模型不能挂载工具。
Skills 和导入定义不会授予权限，也不会配置服务器凭据。

任务页显示进度、共享预算、子运行、模型报告的来源与待确认操作。批准前检查具体操作和
参数；模型提供的来源不代表已经核实。只有明确点击保存，完成的结果才会写入 Documents。

每次运行需单独开启后台执行。可按需在 Android 中设置电池「无限制」、锁定最近任务卡片，
但不能保证厂商系统不杀进程。等待确认会释放执行资源；通知只打开任务，不会自动批准或续跑。
进程中断后，继续操作会重新检查准入；外部效果未知时不能自动重放。Legacy 记录只读，需新建
运行并重新授权。智能体定义包含在设置备份中，确认凭证不会恢复。Token 总量可能含估算，
价格未知不等于免费。

<a id="goal"></a>
## 完成什么

配置 Skills、MCP、智能体和执行限制。

<a id="steps"></a>
## 操作步骤

![选择、配置、确认的三步流程](../assets/setup-flow.svg)

1. 在工具与自动化选择所需能力。

2. MCP 可安装模板或填写名称与地址后保存，随后检查连接和各工具权限。安装模板可能联系远程服务。

3. 工作流限制包括步数、每步调用和输出量；先用低风险任务验证。

<a id="success"></a>
## 成功表现

连接成功和获准执行是不同状态；启用不代表每次回答都调用。

<a id="troubleshooting"></a>
## 常见问题

检查服务地址、网络、审批和全局开关。删除、付费、对外发送仍是高影响操作。

<a id="skill-editor"></a>
## 编辑 Skill

先填写名称、说明和系统提示词；需要时再展开高级选项，设置模型绑定、工具范围或变量。收起高级选项不会清空输入。变量字段必须符合界面要求的 JSON 数组格式，红色错误状态需要先处理。

显式保存后其他页面才能使用修改。切换到另一份 Skill 或取消时，可以继续编辑或放弃；应用被系统终止后不恢复未保存草稿。导入工作流不等于批准执行，仍须检查权限和审阅状态。

<a id="mcp-permissions"></a>
## MCP 的连接与授权

填写名称和服务器地址后保存，再按需要刷新清单。保存新地址不会代替连接检查。模板安装可能立即联系模板标注的远程地址；先检查认证方式和工具范围。

连接成功只表示清单可用。逐项授权工具，并检查全局 MCP 开关；不要因一个工具不可用而直接开放所有写入或破坏性权限。
