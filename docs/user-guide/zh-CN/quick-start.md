# 开始使用

<a id="goal"></a>
## 完成什么

完成第一次对话。云端模型需要网络，服务商可能收费。

<a id="steps"></a>
## 操作步骤

![选择、配置、确认的三步流程](../assets/setup-flow.svg)

1. 打开设置 → 模型与回答 → 服务商，选择服务商。

2. 填写连接信息并保存，选择已配置的模型。不要把密钥发进聊天。

3. 返回聊天发送简短问题；请求由你的发送或测试操作触发。

<a id="success"></a>
## 成功表现

收到回复即可继续或新建会话。

<a id="troubleshooting"></a>
## 常见问题

没有模型时检查服务商启用状态、模型名称和权限。见[模型配置](models.md#steps)。
