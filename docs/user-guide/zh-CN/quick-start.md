# 开始使用

<a id="goal"></a>
## 完成什么

完成第一次对话。云端模型需要网络，服务商可能收费。

<a id="steps"></a>
## 操作步骤

![选择、配置、确认的三步流程](../assets/setup-flow.svg)

1. 打开设置 → 模型与回答 → 服务商 → 添加，导入已有配置或手动填写。不要把密钥发进聊天。

2. 核对并保存连接，再选择用于新对话的模型。保存和选择不发送测试请求。

3. 回到首页直接输入并发送；聊天、工具任务和代码工作使用同一个入口，不必先选模式。

<a id="success"></a>
## 成功表现

收到回复即可继续或新建会话。

<a id="troubleshooting"></a>
## 常见问题

没有模型时检查服务商启用状态、模型名称和权限。见[模型配置](models.md#steps)。
