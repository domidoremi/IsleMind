# 个性化

<a id="goal"></a>
## 完成什么

调整外观与交互，不改变模型策略。

<a id="steps"></a>
## 操作步骤

![选择、配置、确认的三步流程](../assets/setup-flow.svg)

1. 打开个性化 → 主题、背景与语言，预览日夜效果。

2. 按需要调整背景强度与动态；敏感时用静态背景和系统减少动态效果。

3. 在交互、助手名称、系统通知入口调整对应选项。

<a id="success"></a>
## 成功表现

主题与语言反映在界面上；通知还需要操作系统权限。

<a id="troubleshooting"></a>
## 常见问题

难读时调整背景、字体和对比度。未保存输入不保证在进程退出后恢复。
