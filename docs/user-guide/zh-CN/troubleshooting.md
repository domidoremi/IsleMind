# 诊断与排障

<a id="goal"></a>
## 完成什么

识别故障环节后再修复。

<a id="steps"></a>
## 操作步骤

![选择、配置、确认的三步流程](../assets/setup-flow.svg)

1. 打开帮助与维护 → 诊断与修复。

2. 区分连接、权限、索引和工具故障，只执行相关修复。

3. 反馈时提供版本、复现步骤和脱敏错误；更新前备份并选择可信来源。

<a id="success"></a>
## 成功表现

重试原操作确认恢复；诊断成功不保证全部功能正常。

<a id="troubleshooting"></a>
## 常见问题

避免一次改多个参数；不发送凭据；重置和清除数据不是通用修复。

Android 的「网络已断开」提示可关闭，继续编辑设置或阅读离线手册。关闭只收起提示，不会恢复连接或自动重试请求。

修改 Android 系统字体大小可能重建页面并丢失未保存草稿；请先保存，再调整系统字体。

### 版本更新

- GitHub APK 版可在设置 → 版本更新中检查更新；下载或校验时可取消。离开此页面也会停止未交给系统安装器的更新，重试会重新下载。
- 检查失败后可立即重试；重复点击不会启动多个下载。没有匹配设备架构的安装包时，不会下载不兼容的 APK。
- 下载后必须通过文件大小与 SHA-256 校验才会打开安装器。安装器打开不代表安装成功，请按系统提示确认；此时需在系统安装器中取消。
- Google Play 版只通过商店更新。点击「前往 Google Play 更新」打开应用商店页面；若无法打开，请在商店搜索 IsleMind。
