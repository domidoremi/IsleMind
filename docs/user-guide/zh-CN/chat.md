# 聊天与附件

<a id="goal"></a>
## 完成什么

发送消息并安全使用文件。

<a id="steps"></a>
## 操作步骤

![选择、配置、确认的三步流程](../assets/setup-flow.svg)

1. 选择或新建会话，检查当前模型。

2. 通过附件入口选文件，发送前核对文件内容和模型是否支持该类型。

3. 需要时停止生成；不同话题可使用新会话。

<a id="success"></a>
## 成功表现

消息和回复保留在当前会话中；文件解析成功不代表模型一定能理解。

回复上方按实际发生的顺序列出活动。正在进行的阶段会实时更新，成功后切换为完成态文案；未发生的阶段不会补列。点击带箭头的活动可单独展开或收起思考摘要、工具输入、执行结果或搜索结果，不会展开其他活动。仅显示服务商明确提供的可展示思考摘要，不显示内部推理原文。等待确认、失败、停止和跳过不会显示为执行成功；模型请求调用工具也不代表工具已经执行。

<a id="troubleshooting"></a>
## 常见问题

检查格式、大小、权限。附件可能发送给服务商；删除本地会话不删除服务商副本。
