# Get started

<a id="goal"></a>
## Outcome

Complete your first conversation. Cloud models need a connection and may incur charges.

<a id="steps"></a>
## Steps

![Choose, configure, confirm](../assets/setup-flow.svg)

1. Open Settings → Models & answers → Providers and choose a provider.

2. Enter connection details, save, and select a configured model. Never paste keys into chat.

3. Return to chat and send a short question. Sending or testing explicitly starts a request.

<a id="success"></a>
## Success

A reply means you can continue or start another conversation.

<a id="troubleshooting"></a>
## Common problems

If no model is available, check provider status, model name, and permissions. See [Models](models.md#steps).
