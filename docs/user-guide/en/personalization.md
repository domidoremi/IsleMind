# Personalization

<a id="goal"></a>
## Outcome

Adjust appearance and interaction, not model policies.

<a id="steps"></a>
## Steps

![Choose, configure, confirm](../assets/setup-flow.svg)

1. Open Personalization → Theme, background & language and check light and dark appearances.

2. Adjust motion and intensity; use static backgrounds and OS reduced motion when needed.

3. Use interaction, identity, and notification entries for their respective options.

<a id="success"></a>
## Success

Theme and language affect the interface; notifications also require OS permission.

<a id="troubleshooting"></a>
## Common problems

For readability adjust background, text size, and contrast. Unsaved input is not guaranteed after process termination.
