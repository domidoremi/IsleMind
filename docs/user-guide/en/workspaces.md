# Workspaces & characters

<a id="goal"></a>
## Outcome

Organize scenario-specific content and characters.

<a id="steps"></a>
## Steps

![Choose, configure, confirm](../assets/setup-flow.svg)

1. Choose a workspace and check the conversation and character.

2. Review source, permissions, and content before importing; try a test conversation.

3. Review pending character, scene, and relationship-memory changes before approval.

<a id="success"></a>
## Success

Content follows the current scenario; pending drafts are not active material.

<a id="troubleshooting"></a>
## Common problems

Check backup scope before restore. Private and pending items may have separate export restrictions; read warnings.
