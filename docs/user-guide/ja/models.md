# モデルと回答

<a id="goal"></a>
## 目的

接続と生成パラメーターを設定します。

<a id="steps"></a>
## 手順

![選択・設定・確認](../assets/setup-flow.svg)

1. プロバイダー一覧の「追加」からインポートまたは手動追加を選びます。保存前に名前、URL、モデル、非表示の認証情報件数を端末内で確認します。重複はスキップか別接続として保存でき、既存設定は上書きしません。

2. 保存後、モデル画面で新しい会話に使うモデルを選びます。必要ならモデル ID を手入力できます。死活監視のテストは前提ではありません。

3. 普段の切り替えはホームのモデル選択から行います。接続画面で名前、URL、認証情報を変更でき、高度な設定と一括管理は必要な時だけ開きます。

<a id="success"></a>
## 完了の確認

他画面は確定済みの値だけを使います。保存は接続成功や無料利用を意味しません。

<a id="troubleshooting"></a>
## よくある問題

401/403 は認証と権限、404 は URL・方式・モデル名を確認します。画像からキーを隠してください。

<a id="generation"></a>
## 生成パラメーター

- **モデルのデフォルト**はカスタム値を送信せず、モデルとプロバイダーに任せます。共通の固定値ではありません。
- **カスタム**ではスライダー、増減ボタン、数値入力を使えます。スライダーは指を離した時だけ確定し、中断した操作は書き込みません。数値入力は「保存」で確定し、既存の範囲チェックが適用されます。フォーカスを外す、折りたたむ、ガイドを読む操作では保存されません。
- 下書きを上書きしないよう、未保存の数値を保存するか保存済みの値を再読み込みしてから、スライダー、増減ボタン、デフォルト切り替えを操作してください。ワークフローの数値とアシスタント名も明示的に保存します。
- 温度はサンプリングに影響しますが、正確さを保証しません。出力上限を増やすと使用量が増える場合があり、モデル側の上限が優先されることもあります。
- 元に戻す操作は、その後変更されていない項目だけに適用されます。

<a id="editing"></a>
## 接続の下書きと保存失敗

接続、認証情報、モデルは同じ下書きを共有し、タブを変えても入力を保持します。新しい認証情報は初期状態で非表示です。空欄なら保存済み情報を維持し、「保存」で確定します。永続化に失敗しても下書きを保持します。外部変更があれば開き直して確認してください。保存やモデル選択で死活監視は行いません。選択成功はローカル設定の永続化を意味し、接続成功ではありません。既存の会話も変更しません。

インポートは確認して保存するだけで、全接続の有効化とテストは勧めません。適用後の永続化が失敗した場合も、再試行で重複追加や後の変更の巻き戻しはしません。閉じても適用済みデータは取り消されません。未送信の入力は明示的な破棄で消去します。

モデル一覧の取得と使用量の手動照会は個別の通信操作です。画面を開いたり保存したりしても実行しません。使用量設定の保存後に手動照会でき、リクエストは一度だけで、返された数値を表示します。以前の失敗は警告として保持します。ネットワークエラーを認証情報の無効と断定せず、モデル選択に再テストを要求しません。
