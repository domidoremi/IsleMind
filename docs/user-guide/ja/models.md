# モデルと回答

<a id="goal"></a>
## 目的

接続と生成パラメーターを設定します。

<a id="steps"></a>
## 手順

![選択・設定・確認](../assets/setup-flow.svg)

1. プロバイダー一覧の「追加」からインポートまたは手動追加を選びます。保存前に名前、URL、モデル、非表示の認証情報件数を端末内で確認します。重複はスキップか別接続として保存でき、既存設定は上書きしません。

2. 保存後、モデル画面で新しい会話に使うモデルを選びます。必要ならモデル ID を手入力できます。死活監視のテストは前提ではありません。

3. 普段の切り替えはホームのモデル選択から行います。接続画面で名前、URL、認証情報を変更でき、高度な設定と一括管理は必要な時だけ開きます。

<a id="success"></a>
## 完了の確認

他画面は確定済みの値だけを使います。保存は接続成功や無料利用を意味しません。

<a id="troubleshooting"></a>
## よくある問題

401/403 は認証と権限、404 は URL・方式・モデル名を確認します。画像からキーを隠してください。

<a id="generation"></a>
## 生成パラメーター

- **モデルのデフォルト**はカスタム値を送信せず、モデルとプロバイダーに任せます。共通の固定値ではありません。
- **カスタム**ではスライダー、増減ボタン、数値入力を使えます。スライダーは指を離した時だけ確定し、中断した操作は書き込みません。数値入力は「保存」で確定し、既存の範囲チェックが適用されます。フォーカスを外す、折りたたむ、ガイドを読む操作では保存されません。
- 下書きを上書きしないよう、未保存の数値を保存するか保存済みの値を再読み込みしてから、スライダー、増減ボタン、デフォルト切り替えを操作してください。ワークフローの数値とアシスタント名も明示的に保存します。
- 温度はサンプリングに影響しますが、正確さを保証しません。出力上限を増やすと使用量が増える場合があり、モデル側の上限が優先されることもあります。
- 元に戻す操作は、その後変更されていない項目だけに適用されます。

<a id="editing"></a>
## 接続の下書きと保存失敗

接続、認証情報、モデルは同じ下書きを共有し、タブを変えても入力を保持します。新しい認証情報は初期状態で非表示です。空欄なら保存済み情報を維持し、「保存」で確定します。永続化に失敗しても下書きを保持します。外部変更があれば開き直して確認してください。保存やモデル選択で死活監視は行いません。選択成功はローカル設定の永続化を意味し、接続成功ではありません。既存の会話も変更しません。

インポートは確認して保存するだけで、全接続の有効化とテストは勧めません。適用後の永続化が失敗した場合も、再試行で重複追加や後の変更の巻き戻しはしません。閉じても適用済みデータは取り消されません。未送信の入力は明示的な破棄で消去します。

モデル一覧の取得と使用量の手動照会は個別の通信操作です。画面を開いたり保存したりしても実行しません。使用量設定の保存後に手動照会でき、リクエストは一度だけで、返された数値を表示します。以前の失敗は警告として保持します。ネットワークエラーを認証情報の無効と断定せず、モデル選択に再テストを要求しません。

接続タブの「接続の参照」を開くと、この接続を使用する会話、ルート、シーン、モデル設定と、現在のモデル・優先・予備の役割を確認できます。参照を選ぶと対応する設定を開きます。端末内の設定を読むだけで、モデルのテストは行いません。レポートには確認時点が表示され、更新すると後の変更を確認できます。未確認の保存済み会話と読み取れない設定は別に表示し、端末内の未送信下書きも件数に含めます。

プロバイダーグループ、すべての接続、無効な接続を削除する前に、確認画面で参照件数と確認範囲を表示します。読み取りに失敗した場合は再試行でき、今回の操作では接続を削除しません。削除すると該当する既定の接続を変更し、そのモデルのお気に入りを削除します。ルート、シーン、会話設定、直近のモデル選択には元の参照が残り、別のモデルへの変更は明示的に行います。既存のメッセージと実行記録は保持されます。

<a id="routing"></a>
## ルーティングプラン

モデル設定または接続管理からルーティングプランを開き、固定モデルか優先モデルと一つの予備モデルを保存します。対象には正確な接続とモデル ID を使い、表示名は識別のためだけに使います。プレビューで両方の対象と別接続への切り替え確認を読めます。保存ではテストリクエストを送信しません。

会話のモデル選択でプランを選ぶと、その会話にコピーを保存します。管理画面でテンプレートを編集または削除しても、選択済みの会話は変更されません。新版を使うには再選択してください。別接続の予備モデルには、初期設定でリクエストごとに確認します。自動切り替えは明示的な選択が必要で、機能、認証、キャンセル、ツールの継続制限も適用されます。

返信の使用量表示からリクエスト詳細を開くと、実際に試した接続とモデル、切り替えの結果、使用量の出典を確認できます。報告されていない上流の識別情報や数値は不明と表示します。詳しくは[リクエストと使用量](usage.md)を参照してください。

<a id="scenes"></a>
## シーンプラン

設定のシーンプランで、調査や執筆などの構成に名前を付けて保存できます。完全な AI 設定の「シーンプランとして保存」は現在の会話の設定をコピーし、「シーンプランを選択」は保存済みプランを開きます。編集画面は会話、リソース、コンテキストの三つのタブに分かれ、保存後に選択できます。

各項目で「現在を維持」を選べます。「使用しない」は適用先のツールまたはナレッジ範囲を閉じ、「指定」には少なくとも一項目の選択が必要です。コンテキスト閾値とツール定義モードはグローバル設定の継承か会話専用の値を選べます。スキル変数は型と初期値に従い、必須項目を入力してください。既存の権限と機能スイッチも適用されます。プロバイダー内蔵検索とメモリはコンテキスト設定で個別に管理します。

既存または新しい会話を選び、適用プレビューで正確な接続とモデル、優先と予備、別接続への切り替え確認、変更前後の値を確認してください。参照の欠落、アクセス制限、無効な変数、実行中の会話は適用を止めます。関連する設定が変わったらプレビューを更新します。保存に失敗しても下書きを保持し、再試行できます。テンプレート競合時は再読み込みか新規保存を選べます。

適用すると、既存の会話には独立した構成のコピーを保存し、過去のメッセージを維持します。新しい会話は未送信の下書きで、最初のメッセージは自分で送信します。プレビュー、保存、適用ではプロバイダーをテストせず、スキルの初回メッセージも送信しません。プランの編集や削除は適用済みの会話を変更しません。「前回適用」は出典の記録で、テンプレートとの連動ではありません。スキル、ツール、ナレッジの定義は各一覧で管理され、更新した構成が必要な場合は再度プレビューして適用します。
