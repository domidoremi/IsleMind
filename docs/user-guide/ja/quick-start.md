# はじめに

<a id="goal"></a>
## 目的

最初の会話を始めます。クラウドモデルには通信が必要で、料金が発生する場合があります。

<a id="steps"></a>
## 手順

![選択・設定・確認](../assets/setup-flow.svg)

1. 設定 → モデルと回答 → プロバイダー → 追加から、設定をインポートするか手入力します。キーは会話に貼り付けないでください。

2. 接続を確認して保存し、新しい会話に使うモデルを選びます。保存と選択ではテストを送信しません。

3. ホームでそのまま入力して送信します。回答、ツール作業、コードは同じ入口を使い、モード選択は不要です。

<a id="success"></a>
## 完了の確認

回答が届いたら、会話を続けるか新しい会話を作れます。

<a id="troubleshooting"></a>
## よくある問題

モデルがない場合は有効化、モデル名、権限を確認します。[モデル設定](models.md#steps)を参照してください。
