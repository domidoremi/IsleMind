# はじめに

<a id="goal"></a>
## 目的

最初の会話を始めます。クラウドモデルには通信が必要で、料金が発生する場合があります。

<a id="steps"></a>
## 手順

![選択・設定・確認](../assets/setup-flow.svg)

1. 設定 → モデルと回答 → プロバイダーでサービスを選びます。

2. 接続情報を保存し、設定済みモデルを選びます。キーはチャットに貼り付けないでください。

3. チャットで短い質問を送信します。送信やテストの操作でリクエストが始まります。

<a id="success"></a>
## 完了の確認

回答が届いたら、会話を続けるか新しい会話を作れます。

<a id="troubleshooting"></a>
## よくある問題

モデルがない場合は有効化、モデル名、権限を確認します。[モデル設定](models.md#steps)を参照してください。
