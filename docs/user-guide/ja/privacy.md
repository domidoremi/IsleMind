# データとプライバシー

<a id="goal"></a>
## 目的

保存範囲を理解して安全にバックアップ・復元します。

<a id="steps"></a>
## 手順

![選択・設定・確認](../assets/setup-flow.svg)

1. バックアップと復元で種類と機密情報の警告を確認します。

2. 復元の範囲、件数、差分を確認し、不明なら先にバックアップします。

3. アクセス、プロキシ、ログは専用項目で変更し、消去前に対象を確認します。

<a id="success"></a>
## 完了の確認

書き出したファイルを保管し、実際の結果で復元を確認します。

<a id="troubleshooting"></a>
## よくある問題

バックアップや未加工ログを公開しないでください。端末で消去してもサービス側のコピーは残ります。

<a id="advanced-policy"></a>
## 詳細設定の保存範囲

プロキシのアドレス、ログの上限、アクセスリストなどのテキスト項目は明示的に保存します。フォーカスを外す、折りたたむ、ガイドを読むだけでは保存されません。未保存の入口から編集中の項目を表示できます。再読み込みはその項目の入力を破棄し、確定済みの値を読み込みます。

接続先、アクセス規則、ログの外部送信には汎用の元に戻す操作はありません。外部ログを有効にする前に送信先と秘匿化の範囲を確認してください。費用不明は無料を意味しません。保存失敗時にも入力は保持されますが、一部の書き込みが完了している可能性があり、複数の認証情報をまとめた原子的なロールバックは保証されません。

<a id="content-reporting"></a>
## AI の返信を報告する

AI の返信のその他メニューから報告を開き、抜粋を編集して理由と任意の補足を入力し、プレビュー後に明示的に送信します。送信先とプライバシーポリシーを確認し、キーや個人情報を手動で取り除いてください。自動の秘匿化ですべての機密情報を検出できるとは限りません。報告には抜粋、理由、補足、報告 ID、アプリと形式のバージョンが含まれます。会話全体、添付ファイル、サービスの認証情報、内部トレースは自動添付されません。受信側が IP アドレスなどの接続情報を処理する場合はあります。

運営者やプライバシーポリシーが未設定の場合は送信できません。受領の表示は審査や対応の完了を意味しません。画面を離れる、アプリをバックグラウンドにする、待機を停止する操作は端末側の待機を中止しますが、すでに届いた可能性のある報告は撤回できません。失敗やタイムアウトも未着の証明にはなりません。再試行前に画面を確認し、同じ報告を繰り返し新規作成しないでください。
