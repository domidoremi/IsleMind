# カスタマイズ

<a id="goal"></a>
## 目的

モデル方針を変えずに外観と操作を調整します。

<a id="steps"></a>
## 手順

![選択・設定・確認](../assets/setup-flow.svg)

1. カスタマイズ → テーマ・背景・言語で明暗の表示を確認します。

2. 背景の動きと強さを調整し、必要なら静止背景と OS の動きを減らす設定を使います。

3. 操作、名前、通知はそれぞれの項目で変更します。

<a id="success"></a>
## 完了の確認

テーマと言語が反映され、通知には OS の許可も必要です。

<a id="troubleshooting"></a>
## よくある問題

読みづらい場合は背景、文字サイズ、コントラストを調整します。プロセス終了後の未保存入力は保証されません。
