# ツールと自動化

<a id="agent-tasks"></a>
## エージェントタスク（高度な機能）

設定の「ツールと自動化」でエージェントを作成し、会話のオプションからタスク画面を開きます。
通常のチャットは独立レビューを追加しません。信頼できるアクション能力のないモデルではツールを
利用できません。Skills や定義のインポートで権限やサーバー認証情報が設定されることはありません。

タスク画面では進捗、共有予算、子タスク、モデルが提示した出典、確認待ちの操作を確認できます。
具体的な操作と引数を確認してから承認してください。提示された出典は検証済みとは限りません。
完成した結果を Documents に保存するには、明示的な保存操作が必要です。

一つの応答で複数の操作が提案されることがあります。項目番号は確認待ちの順番であり、
一括承認ではありません。操作ごとに元ファイル、保存先、操作内容を確認してください。
拒否や期限切れはその項目と同じバッチの残りを実行させませんが、完了した操作は取り消しません。
期限切れ後は実行しない結果を返すことだけが可能です。モデルの成功報告だけで判断せず、
各操作の結果にある対象 URI、コピー済みバイト数、完了手順を確認してください。
部分書き込み、結果の欠落や不明な外部効果がある場合は、再実行せず実際の対象を先に確認します。

バックグラウンド実行は実行ごとに有効化します。Android の電池設定を「制限なし」にする、
最近のアプリでロックする等の設定が役立つ場合がありますが、OEM による終了は防げません。
確認待ちは実行リソースを解放し、通知はタスクを開くだけです。中断後の続行では再確認し、外部効果が
不明な操作は自動再実行しません。Legacy 記録は読み取り専用です。新しい実行で再承認してください。
定義は設定バックアップに含まれますが承認は復元されません。トークン数には推定値が含まれる場合があり、
料金不明は無料を意味しません。

一時停止中や確認待ちの実行は、アプリを再起動しても自動再開せず、承認期限も延長されません。
再開可能な一時停止状態でのみ明示的に続行できます。外部効果の確認が必要な実行や停止済みの
実行は続行できません。端末側の停止はサービス側の課金停止を保証しません。完全な使用量を
取得できなかった中断リクエストの予約量や推定量は、再起動後も予算に残ることがあります。

<a id="unified-work"></a>
## 一つの会話でツールとコードを扱う

ホームの入力欄は一つです。通常の回答に追加の計画や独立レビューは不要です。ツール作業も同じ Model + Harness が担い、既存の権限、予算、操作ごとの承認を守ります。再利用するエージェント定義は高度な選択肢であり、初回会話の前提ではありません。

入力欄の「+」にある「コードとファイル」を開いた時だけ、アプリ内のワークスペースのパスを一覧表示します。選択は下書きへの追加だけで、送信や権限の付与は行いません。送信後は許可済みツールで関連内容を読み取る場合があります。添付や貼り付けでコードの相談もできます。書き込み対応環境では小さなファイルの変更全体を差分表示し、承認後にも版を確認します。安全に全体を確認できない変更は承認できません。未対応の実行やテストを完了したとは表示しません。

回答本文を優先し、実際の処理は初期状態で折りたたみます。未使用の能力は表示しません。詳細は展開して確認でき、承認待ち、失敗、不明な外部効果は常に確認できます。折りたたみで処理は止まらず、展開で再試行もしません。

<a id="goal"></a>
## 目的

Skills、MCP、エージェントと実行上限を設定します。

<a id="steps"></a>
## 手順

![選択・設定・確認](../assets/setup-flow.svg)

1. ツールと自動化で機能を選びます。

2. MCP テンプレートを導入するか名前と URL を保存し、接続と各権限を確認します。導入時に外部接続する場合があります。

3. 手順数、呼び出し回数、出力量を制限し、低リスクの作業で試します。

<a id="success"></a>
## 完了の確認

接続と実行承認は別の状態です。有効化しても毎回使われるとは限りません。

<a id="troubleshooting"></a>
## よくある問題

URL、通信、承認、全体設定を確認します。削除、課金、外部送信には注意が必要です。

<a id="skill-editor"></a>
## Skill を編集する

名前、説明、システムプロンプトから入力します。モデルの割り当て、ツール範囲、変数が必要な場合だけ詳細設定を開きます。折りたたんでも入力は消えません。変数は指定の JSON 配列形式で入力し、エラーを解消してから保存します。

他の画面には明示的に保存した変更だけが反映されます。別の Skill への切り替えやキャンセル時には、編集の継続か破棄を選べます。プロセス終了後の下書き復元はありません。ワークフローのインポートは実行の承認ではありません。権限と審査状態を確認してください。

<a id="mcp-permissions"></a>
## MCP の接続と承認

名前とサーバーアドレスを保存し、必要に応じてマニフェストを更新します。アドレスの保存は接続確認ではありません。テンプレートのインストール時には記載された接続先へ直ちに通信する場合があるため、認証方式とツール範囲を先に確認します。

接続済みは一覧が利用できる状態であり、すべてのツールの承認を意味しません。ツールごとの承認と MCP 全体のスイッチを確認してください。利用できないツールを直すために、すべての書き込み権限や破壊的操作を許可しないでください。
