# ワークスペースとキャラクター

<a id="goal"></a>
## 目的

場面別の内容とキャラクターを管理します。

<a id="steps"></a>
## 手順

![選択・設定・確認](../assets/setup-flow.svg)

1. ワークスペースを選び、会話とキャラクターを確認します。

2. 取り込み前に配布元、権限、内容を確認し、テスト会話で試します。

3. キャラクター、場面、関係メモリの変更案を確認して承認します。

<a id="success"></a>
## 完了の確認

内容は現在の場面で使われ、保留下書きは反映済み資料ではありません。

<a id="troubleshooting"></a>
## よくある問題

復元前に範囲を確認します。非公開項目や保留項目には別の書き出し制限がある場合があります。
