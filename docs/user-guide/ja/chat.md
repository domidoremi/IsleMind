# チャットと添付

<a id="goal"></a>
## 目的

メッセージとファイルを安全に利用します。

<a id="steps"></a>
## 手順

![選択・設定・確認](../assets/setup-flow.svg)

1. 会話を選ぶか作成し、モデルを確認します。

2. 添付ファイルの内容とモデルの対応形式を確認して送信します。

3. 必要なら生成を停止します。別の文脈には新しい会話を使います。

<a id="success"></a>
## 完了の確認

会話内にメッセージが残ります。解析成功はモデルの理解を保証しません。

<a id="troubleshooting"></a>
## よくある問題

形式、容量、権限を確認します。添付はサービスへ送信される場合があり、端末での削除ではサービス側のコピーは消えません。
