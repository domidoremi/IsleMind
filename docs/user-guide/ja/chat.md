# チャットと添付

<a id="goal"></a>
## 目的

メッセージとファイルを安全に利用します。

<a id="steps"></a>
## 手順

![選択・設定・確認](../assets/setup-flow.svg)

1. 会話を選ぶか作成し、モデルを確認します。

2. 添付ファイルの内容とモデルの対応形式を確認して送信します。

3. 必要なら生成を停止します。別の文脈には新しい会話を使います。

<a id="success"></a>
## 完了の確認

会話内にメッセージが残ります。解析成功はモデルの理解を保証しません。

返信の上には、実際に発生した順序で各処理が表示されます。進行中の表示は成功後に完了形へ変わり、発生していない段階は追加されません。矢印のある項目をタップすると、その項目の思考の要約、ツール入力、実行結果、検索結果だけを展開・折りたたみできます。表示用として明示された要約のみを表示し、内部推論の原文は表示しません。確認待ち、失敗、停止、スキップは実行成功として表示されず、モデルによるツールのリクエストも実行済みとは区別されます。

<a id="troubleshooting"></a>
## よくある問題

形式、容量、権限を確認します。添付はサービスへ送信される場合があり、端末での削除ではサービス側のコピーは消えません。
