# 文書

<a id="goal"></a>
## 目的

編集を続けたい内容を保存します。

<a id="steps"></a>
## 手順

![選択・設定・確認](../assets/setup-flow.svg)

1. 一覧で文書を作成または開きます。

2. タイトルと本文を編集し、プレビューして保存します。

3. 競合時は再読み込みやコピー保存で新しい内容を保護します。

<a id="success"></a>
## 完了の確認

保存した文書は再度開けます。未保存入力はバックアップではありません。

<a id="troubleshooting"></a>
## よくある問題

保存失敗時は入力を保持してエラーを確認します。共有前に個人情報と認証情報を確認してください。
