# 使用量と費用

<a id="goal"></a>
## 目的

利用記録とサービスの請求を区別します。

<a id="steps"></a>
## 手順

![選択・設定・確認](../assets/setup-flow.svg)

1. モデルと回答 → 使用量で期間と範囲を選びます。

2. リクエストとトークン数を確認し、失敗、取消、記録漏れに注意します。

3. 推定や不明な費用はサービスの請求を確認します。不明は無料ではありません。

<a id="success"></a>
## 完了の確認

指標は傾向を示し、正式な請求ではありません。

<a id="troubleshooting"></a>
## よくある問題

期間、単価、記録範囲を確認します。端末の記録削除で料金は取り消されません。
