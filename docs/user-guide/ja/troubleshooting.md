# 問題の解決

<a id="goal"></a>
## 目的

失敗している段階を確認して修復します。

<a id="steps"></a>
## 手順

![選択・設定・確認](../assets/setup-flow.svg)

1. ヘルプと保守 → 診断と修復を開きます。

2. 接続、権限、索引、ツールの問題を区別し、関係する修復だけ行います。

3. 報告にはバージョン、手順、機密情報を除いたエラーを添えます。更新前にバックアップし、信頼できる配布元を使います。

<a id="success"></a>
## 完了の確認

元の操作で確認します。診断成功だけですべての機能が正常とは限りません。

<a id="troubleshooting"></a>
## よくある問題

複数の設定を一度に変えず、認証情報を送らないでください。初期化や削除は万能な修復ではありません。
