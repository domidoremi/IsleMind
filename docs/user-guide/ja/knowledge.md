# ナレッジとメモリ

<a id="goal"></a>
## 目的

資料を取り込み、長期メモリを確認します。

<a id="steps"></a>
## 手順

![選択・設定・確認](../assets/setup-flow.svg)

1. ナレッジと検索 → ナレッジで資料を取り込み、解析と索引を確認します。

2. 内容とフィルターを確認し、会話の参照を検証します。

3. 保留メモリを確認し、正確で保存に適した情報だけを承認します。

<a id="success"></a>
## 完了の確認

索引済み資料が検索対象になり、承認メモリは現在の方針で使われます。

<a id="troubleshooting"></a>
## よくある問題

失敗時は形式、容量、依存モデルを確認します。メモリの却下は元ファイルの削除とは異なります。

<a id="import-and-check"></a>
## 最初の資料を取り込む

1. ナレッジのファイル取り込みから資料を選びます。短い文章なら、テキスト貼り付け欄を開き、タイトルと本文を入力して取り込みます。
2. 一覧の状態を確認します。**索引作成中**は未完了、**失敗**はエラーの確認が必要です。**空の内容**は資料として使えません。一覧に表示されただけで完了と判断しないでください。
3. 資料が多い場合はフィルターを開き、状態やキーワードで絞り込みます。見つからないときは、同じファイルを再度取り込む前にフィルターを解除します。
4. チャットに戻り、資料にある具体的な事実を質問し、回答の出典を開いて原文を確認します。索引作成の成功は検索可能になったことを示し、すべての質問でのヒットを保証しません。

検索範囲と必要なモデルは[ネット検索と情報検索](search.md#dependencies)を参照してください。資料がモデルのコンテキストに含まれる場合があります。選択したプロバイダーへ送信すべきでない情報がないか、取り込み前に確認してください。

<a id="review-memory"></a>
## メモリの確認と無効化

メモリ画面で保留、有効、無効の件数を確認してから、審査キューを開きます。出所や低信頼度で絞り込めます。信頼度は判断の補助であり、正確さの証明ではありません。

内容を一件ずつ確認して承認します。一括操作の前に、対象が現在の絞り込み結果か、保留中の全件かをボタンの説明と件数で確認します。古くなったメモリは無効化し、必要に応じて復元できます。元のチャットや資料は変更されません。

回答にメモリが使われない場合は、メモリのスイッチ、項目の状態、検索範囲を先に確認します。ヒットを増やすために誤った情報を承認しないでください。
