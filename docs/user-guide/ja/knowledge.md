# ナレッジとメモリ

<a id="goal"></a>
## 目的

資料を取り込み、長期メモリを確認します。

<a id="steps"></a>
## 手順

![選択・設定・確認](../assets/setup-flow.svg)

1. ナレッジと検索 → ナレッジで資料を取り込み、解析と索引を確認します。

2. 内容とフィルターを確認し、会話の参照を検証します。

3. 保留メモリを確認し、正確で保存に適した情報だけを承認します。

<a id="success"></a>
## 完了の確認

索引済み資料が検索対象になり、承認メモリは現在の方針で使われます。

<a id="troubleshooting"></a>
## よくある問題

失敗時は形式、容量、依存モデルを確認します。メモリの却下は元ファイルの削除とは異なります。
